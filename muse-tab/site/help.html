快速上手

四步做一首谱：选场景建谱 → 录入 → 排版 → 导出。

第 1 步 · 按场景建谱

点顶栏「新建」，从八种场景中选择：弹唱谱 / 独奏谱 / 钢琴弹唱谱 / 钢琴独奏谱 / 歌谱 / 教学对照谱 / 器乐五线谱 / 功能谱——按「我要干什么」选，不需要懂记谱法。填写标题、调号、拍号、速度即可开始。已有素材可以不从零建：新建弹窗里还有「导入 MusicXML」「导入 MIDI」「哼唱成谱」三个入口，或在「曲谱库」选预设改编。

第 2 步 · 录入

点哪写哪：TAB 区点弦位敲品位数字 0–24；简谱区点数字位敲 0–7；点歌词行直接打字。填好和弦后，「节奏型库」可一键按指法生成整小节伴奏；钢琴弹唱谱标好和弦后点「伴奏织体」自动生成双手伴奏。

第 3 步 · 排版

顶栏「排版」选基准纸张（A5/A4/A3）与疏密（紧凑/标准/宽松），需要时手动微调缩放与行距；「预览」查看多页成品效果。

第 4 步 · 导出

「打印」弹窗集中了全部出口：打印 PDF、高清 PNG、MusicXML、MIDI、分享卡 PNG、互动谱 HTML。所有修改实时自动保存在本机。

编辑器右下角状态条会实时校验节拍：小节时值与拍号不符会标红，并给出绿色修复建议，一键采纳。
当前版本为单窗口工作流：新建 / 打开 / 导入都会替换当前谱面；有未入库的修改时会先弹出确认对话，可一键「存入我的曲谱」再继续，不会丢稿。

每种场景一节：构成、典型工作流与专属功能。

钢琴弹唱谱和弦＋伴奏织体自动生成双手（纯伴奏）即兴伴奏、教师考编、幼师
钢琴独奏谱高音＋低音大谱表（右手/左手）钢琴独奏与练习曲
歌谱简谱 1–4 声部＋多段歌词独唱、合唱及二胡/古筝等民乐

弹唱谱（吉他 / 尤克里里）

三行对齐版式：TAB 点弦位敲品位，简谱与歌词自动同列对齐；输入和弦名自动画和弦图。工作流：标和弦 → 「节奏型库」按指法一键生成整小节伴奏（Shift 跨小节多选可批量套用）→ 补歌词。全套演奏技巧记谱与扫弦琶音箭头见「录入与技巧」。尤克里里为 4 弦 GCEA，谱表 / 和弦图 / 播放调弦全部自适配。

独奏谱

TAB 上方叠一行标准五线谱（Guitar Pro 式联排），品位自动按调性拼写成五线谱音高，两行始终逐列对齐；无歌词行，专注指弹与旋律细节。

钢琴弹唱谱

面向即兴伴奏 / 考编的核心工作流：① 在小节里标注和弦（或点「一键配和弦」按功能和声自动建议，已填的小节不覆盖）→ ② 点「伴奏织体」从 11 套按难度分级的织体中选一套（柱式 / 半分解 / 全分解琶音 / 进行曲 / 圆舞曲 / 儿歌伴奏……）→ ③ 自动生成双手伴奏音符——生成的是可编辑真音符，可逐段重生成。主旋律交给演唱者，歌词行做演唱提示。

钢琴独奏谱

高音＋低音大谱表花括线联排，上下谱表严格纵向对齐。和音输入：「和音」按钮输唱名串（如 35 自动向上排列），或在五线谱上 Ctrl+点击直接加音；踏板记号与 1–5 指法数字见「记号大全」。

歌谱

简谱 1–4 声部＋最多 5 段歌词。每个声部可独立切换记谱法：简谱 / 高音谱表 / 低音谱表 / 中音谱表，还可在谱表下附加简谱对照行；合唱分声部、民乐（二胡/古筝等）记谱通用。

教学对照谱

五线谱＋简谱行逐列对齐＋歌词，音乐课堂与考级教学的标配版式。配合「智能配谱」可从一条主旋律一键产出「五线谱＋简谱＋歌词」伴奏教学谱。

器乐五线谱

单谱表出版级刻版，高音 / 中音 / 低音谱号可选；SMuFL/Bravura 真字形、严格系统头部（谱号-调号-拍号）与刻版规则，直接可用于艺考视奏与声部谱。

功能谱

简谱＋级数和弦：级数按调号自动换算（C 调 Am→6m、G/B→5/7），换调级数即时跟随，级数/音名一键切换。「纯和弦谱」模式则渲染为小节格＋节奏斜线，一页纸带乐队排练。

录入与技巧

音符、时值、演奏技巧与小节段落。

时值与节奏

顶部编辑栏常驻：单时值（QWERT = 全 / 2 / 4 / 8 / 16 分）与常用节奏组合；「节奏型库」整小节套用，可 Shift 跨小节多选后批量应用。

附点与双附点

「附点」按钮（或 .）循环：无 → 附点（×1.5）→ 双附点（×1.75）→ 无。加附点时下一音自动减半补拍，双附点再减半。按出版规则分档：全 / 2 / 4 / 8 分音符可双附点，16 分限单附点，32 分不可附点。简谱按国标惯例呈现：附点只画在四分及更短的音上，附点二分记「数字＋2 条增时线」、附点全音符 5 条增时线。

音符操作

＋后插 / ＋前插（Insert / Shift+Insert）在任意位置加音符；休止符整列休止（吉他谱按时值显示 𝄽𝄾𝄿）；清单音（Backspace）只清当前弦位；拆分 / 合并 / 删音符自由组合——自由编辑优先，不受拍号强制，节拍检查给绿色修复建议。

演奏技巧（吉他 / 尤克里里）

选中音符点技巧图标：滑弦 S / 击勾弦 H·P / 揉弦 / 泛音 / 点弦 / 闷音 / 无头无尾滑音，S/H/P 自动连线；推弦与跨选连线用 Ctrl 选两音。揉弦波浪线随时值延长、可扩选覆盖范围；闷音 P.M. 为范围标记（虚线＋末端竖钩）。已推弦的音符再点推弦按钮可标注推弦幅度（full / ½ / ¼ / 1½，显示在弧线上方）。扫弦/琶音箭头方向与覆盖弦数都可点谱面调整，教材式 ×记谱一键切换。

连音线与连音

连音线：单选自动连相邻音，Ctrl 选两音可跨过中间音符相连；3/5/6/7 连音原地拆分、总时值不变。

小节与段落

「小节」面板插入/删除小节；「段落·反复·跳转记号」设置 𝄆𝄇 反复、第一/二段（开口括线）、D.C./D.S./𝄋/Fine/⊕ Coda、段落线/终止线。点击小节线弹出同款菜单；按住小节线约半秒可独立选中该小节的单个声部，Ctrl+C/V 复制粘贴。段落标记、转调标记与小节反复 𝄎 见「记号大全」。

记号大全

「记号」面板与小节面板里的全部音乐记号——全部同步进出 MusicXML。

音符记号（「记号」面板）

记号写法用法
延长号 𝄐音符/休止上方选中音（TAB 列同法）点「延长号」，自由延长该音时值；再点取消
跳音 ·音符上方圆点短促轻巧；与其他三件演奏法互斥
断音（顿音）▼音符上方楔形短促有力
保持音 −音符上方横线唱/奏足时值
重音 >音符上方 >强调该音
换气 v列右上角小 v本音之后换气（声乐/合唱），不占对齐宽度

演奏法在五线谱贴符头反符干侧、简谱按国标形态绘制；四件互斥、再点取消。

力度与渐强渐弱

「力度/速度」弹窗（每项中文说明）：ppp–ff、fp、sfp、cresc./dim.、rit./accel.，力度即时影响播放音量。渐强渐弱范围括线：Ctrl 选首末两音后在弹窗里选 < / >（或 cresc./dim.），谱面画出起止范围的开口楔形（文字形态为文字＋虚线延长），跨行自动断线续画。

钢琴记号（仅五线谱声部显示）

踏板 Ped.____*：「踏板Ped.」在本列起画 Ped. 文字＋延续线，至「踏板收*」列画 * 收尾；连续踩下自动换踏断线，跨行断线续画。指法数字：点「指法1-5」进入直录，按数字键 1–5 写入符头上/下方小数字（低音谱表标下方，和音按音高堆叠），0/退格清除，Esc 退出。

小节级记号（「小节」面板）

记号用法
段落标记「段落标记…」输入文字（如 前奏 / A / 副歌），小节头上方方框粗体显示，乐队排练与教学定位；留空清除
转调标记「转调标记…」选新调，小节头上方标「转1=X」（流行歌尾段升调常用）；全曲换调时随之自动移调
小节反复 𝄎「同前1小节」/「同前2小节」把小节省写为反复记号：数据保留、节拍校验豁免、播放自动展开为源小节内容；再点取消

装饰音与其他（简谱声部）

♯♭♮ 变音记号（小节内自动进位省略）、八度点 ±3、倚音（最多 3 音＋直角连线，可点击再编辑）、上下波音 / 颤音 tr / 回音。

以上全部记号（延长号 / 演奏法 / 换气 / 渐强渐弱括线 / 排练标记 / 转调 / 踏板 / 指法 / 小节反复）都已接入 MusicXML 导出与导入，往返一致——放心与 MuseScore 等软件互传。

和弦与级数

和弦弹窗、把位方案与功能谱级数。

输入和弦

选中位置打开和弦弹窗：左列选主音（12 键）、性质（maj/m/7/maj7/sus/add9/dim/aug 等 22 类型全根音可用）与转位（G/B 式斜杠低音）；右列是可编辑和弦图——竖式点格直接点按位，顶部标 ×/○，可拖把位窗。「▶ 试听」按指法自低音弦琶音试听；「把位方案」给出同一和弦的多个把位卡，点选即载入。自定义指法可「保存」进「我的和弦」。

和弦图与移调

弹唱谱输入和弦名自动画和弦图并按指法重排；升降号按出版惯例显示在主音左上角（♯C / ♭B）。顶栏换调时和弦名自动换根音（含斜杠低音）、TAB 品位整体统一平移。

一键配和弦

有旋律的谱面点「一键配和弦」：按功能和声自动建议全曲和弦，已填的小节不覆盖；配好后可直接接「伴奏织体」或「智能配谱」。

功能谱级数

选中音符点「和弦/级数」：以级数为主构建（级数 × 类型扩展 × 转位低音），本调常用库＋最近使用一键选用，支持调外和弦；谱面按 1=调号 显示级数，级数/音名一键切换，点击标注可再编辑，换调级数即时跟随。

歌词与填词

逐字对位、多段歌词与智能填词。

逐字输入

点歌词行直接打字，Enter/Tab 跳到下一个音。多段歌词（最多 5 段）在左栏「歌词」管理，段序号点击即切换。

智能填词

把整段歌词粘进「智能填词」，自动逐字分配到每个可唱音：自动跳过休止符与连音线延续音；标点跟随前字旁挂、不占对位；- 手动跳过一个音；英文单词整体成词。下方实时预览对齐结果，可点选任意音作为填词起点，「换行对齐乐句」让每行歌词从新小节开始。

一字多音（连音线连接不同音高）会自动只占一个字——melisma 场景不用手动补 -。

排版与打印

出版级排版三步走，预览与打印。

排版面板（顶栏「排版」）

可拖动浮层、实时生效、参数随曲谱保存：

步骤作用
① 基准纸张A5 / A4 / A3，选定后固定——决定每页容量（A3 容纳更多小节与行）
② 智能排版紧凑 / 标准 / 宽松，按出版谱对数时值间距自动缩放行距与间距
③ 手动微调整体缩放（纸张外框不变）、行距（可分选吉他谱·简谱·歌词）、间距；百分比数字点击可输入精确值

内容驱动版式

小节宽度随内容疏密自动伸缩——一拍一个四分音符的小节自然窄于每拍两个八分的小节；每行小节数自由适配，密集小节可独占一行；32 分/三连音逐字带词也能被自动撑开、歌词永不重叠。

打印预览

顶栏「预览」：A5/A4/A3 适配、缩放（±/Ctrl 滚轮/适配/整页）、多页竖排/横排/网格排布；纯净成品谱可直接进入打印。「曲谱反色」仅作用于屏幕浏览，打印自动回到白纸黑字。文件导出的全部出口见下一篇「导入与导出」。

导入与导出

接入 AI 转谱与专业软件生态：三种进、六种出。

导入（顶栏「新建」弹窗内）

入口说明
导入 MusicXMLMuseScore / Finale / AI 转谱的 .musicxml/.xml 直接进编辑器精修；调号、拍号、音高拼写、连音线与各类记号一并读入
导入 MIDIDAW / 编曲软件的 .mid（SMF 0/1）导入，按 16 分网格自动量化成谱；钢琴类自动分手
哼唱成谱对麦克风清唱一段（安静环境效果更佳）：自动识别音高、自动定调、量化成简谱草稿进编辑器精修

导入会替换当前窗口的谱面；有未入库修改时会先弹确认对话，可一键存入「我的曲谱」再继续。

导出（顶栏「打印」弹窗，六个出口）

出口说明
打印 PDF浏览器打印（另存为 PDF），白纸黑字省墨规范
导出 PNG高清 2× 图片，发群、贴讲义
导出 MusicXML进 MuseScore/Finale/Sibelius 继续编辑或印刷；记号与双附点等往返一致
导出 MIDI标准 SMF：连音合并长音、和音齐备、TAB 轨含变调夹，进 DAW 或跟弹
分享卡 PNG竖版品牌谱面卡，微信 / 朋友圈 / 小红书直接转发
互动谱 HTML自包含单文件：对方浏览器打开即可播放 / 倍速 / 节拍器 / 移调 / 进谱架，无需安装

备份

Ctrl+S 导出 .mtab.json 工程文件（完整数据，可再导入）；「保存」存入本机「我的曲谱」；个人中心提供 SHA-256 版权时间戳存证。

播放与跟练

真实音色试听、节拍器、倍速、循环与谱架。

播放控制

空格 或 ▶：点播放、再点暂停、再点继续（音频精确冻结）；⏮ 回到开头并停住。底部音轨区可换音色、独奏/静音各声部、调节音量摆位；力度记号即时影响播放音量。

节拍器与倍速

播放条「节拍器」：播放时叠加拍点声，每小节第一拍重音，跟拍练习用。「倍速」六档 0.25× / 0.5× / 0.75× / 1× / 1.25× / 1.5×——只改播放快慢，不改曲谱速度设置，慢速跟练、快速过谱两相宜。

选段循环

小节格进度条一格一小节：点击=单小节循环，拖动=选区循环，再点取消；小节多时自动变密集标尺，点 ▦ 打开大格选择面板精确框选。

反复记号识别

整曲播放自动按记号走：𝄆𝄇 反复、第一/二段换尾、D.C./D.S. 回跳、Fine 结束、⊕ 跳过中段；小节反复 𝄎 自动展开为源小节内容。

谱架模式

常见问题

还没解决？写信给 support@puyouquan.com。

需要付费吗？

制谱与谱库核心功能免费。后续将推出创作者生态（曲谱发布/收益）与增值服务，届时另行公示。

我的曲谱存在哪里？会丢吗？

当前版本实时保存在你的浏览器本机（localStorage），关掉页面也在；建议定期 Ctrl+S 导出 .mtab.json 备份。云端同步在规划中。

怎么同时管理多首曲谱？

当前为单窗口工作流：把做好的谱「保存」进「我的曲谱」，随时打开继续编辑；新建/打开会替换当前谱面，有未入库修改时会先弹确认对话（可一键存入再继续），不会丢稿。

AI 转谱 / MuseScore 的文件能用吗？

能。新建弹窗「导入 MusicXML」直接读入；MIDI 也可导入并自动量化。成品同样能导出 MusicXML/MIDI 回到专业软件——记号、附点等往返一致。

支持手机 / 平板吗？

网页版在平板与手机可打开查看与播放；触控编辑与移动端专属界面在多端规划中。

可以商用我做的谱吗？

你制作的曲谱内容归你；请确保对词曲拥有相应授权。工具内置 SHA-256 时间戳存证辅助确权。

为什么打印出来是白纸黑字，而屏幕上是反色的？

「曲谱反色」是针对屏幕浏览的护眼/投影模式；打印与导出 PDF 时自动回到白纸黑字，省墨且符合成品规范。

音色听起来和真实吉他有差距？

当前使用真实采样＋物理建模混合音色；部署自托管全量音色包后会自动升级，更高保真的合成方案在路线图中。
