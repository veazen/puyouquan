快速上手

三步做一首谱：建谱 → 录入 → 排版打印。

第 1 步 · 建谱

点顶栏「新建」，从八种场景中选择（弹唱谱 / 独奏谱 / 钢琴弹唱谱 / 钢琴独奏谱 / 歌谱 / 教学对照谱 / 器乐五线谱 / 功能谱），填写标题、拍号、调号等信息。也可以「导入 MusicXML / MIDI」「哼唱成谱」，或在「曲谱库」选预设改编。新谱在新窗口打开，多首可同时编辑。

第 2 步 · 录入

TAB 区点弦位敲品位数字 0–24；简谱区点数字位敲 0–7；点歌词行直接打字。填好和弦后，「节奏型库」可一键按指法生成整小节伴奏。

第 3 步 · 排版打印

顶栏「排版」选基准纸张与疏密，「预览」查看多页成品，「打印」输出 PDF 或导出高清 PNG。所有修改实时自动保存在本机。

💡 编辑器右下角状态条会实时校验节拍：小节时值与拍号不符会标红，并给出绿色修复建议，一键采纳。

曲谱类型

八种场景怎么选：按"我要干什么"，不用懂记谱法。

类型构成适合
弹唱谱六线 TAB＋简谱＋歌词＋和弦图（吉他/尤克里里下一步选）弹唱自学与教学，标准弹唱谱版式
独奏谱TAB＋五线谱联排，无歌词行木吉他指弹、电吉他
钢琴弹唱谱和弦＋伴奏织体自动生成双手（纯伴奏）即兴伴奏、教师考编、幼师；主旋律由演唱者担任
钢琴独奏谱高音＋低音大谱表（右手/左手）钢琴独奏与练习曲
歌谱简谱 1–4 声部＋多段歌词独唱、合唱，以及二胡/古筝等民乐记谱
教学对照谱五线谱＋简谱行逐列对齐＋歌词音乐课堂、考级教学
器乐五线谱单谱表（高/中/低音谱号可选）器乐独奏、艺考视奏、声部谱
功能谱简谱＋级数和弦；或纯和弦谱（小节格＋节奏斜线）乐队排练、即兴伴奏和弦推进
💡 已有素材可以不从零建谱：新建弹窗支持「导入 MusicXML」「导入 MIDI」「哼唱成谱」；有旋律的谱面可用顶栏「智能配谱」一键生成即兴伴奏对照谱。

功能谱的级数和弦

选中简谱音符后点「和弦/级数」：以级数为主构建（级数 × 类型扩展 × 转位低音），支持自定义后缀与调外和弦；谱面级数/音名一键切换，点击标注可再次编辑。

录入与技巧

音符、时值、演奏技巧与反复记号。

时值与节奏

顶部编辑栏常驻：单时值（QWERT）与常用节奏组合；「附点」自动把下一音变为一半时值；「节奏型库」整小节套用，可 Shift 跨小节多选后批量应用。

音符操作

＋后插 / ＋前插（Insert）在任意位置加音符；休止符整列休止（吉他谱按时值显示 𝄽𝄾𝄿）；清单音（Backspace）只清当前弦位；拆分 / 合并 / 删音符自由组合。

演奏技巧（吉他 / 尤克里里）

选中音符点技巧图标：滑弦 S / 击勾弦 H·P / 揉弦 / 泛音 / 点弦 / 闷音 / 无头无尾滑音，S/H/P 自动连线；推弦与跨选连线用 Ctrl 选两音。扫弦/琶音箭头方向与覆盖弦数都可点谱面调整。

连音线与连音

连音线：单选自动连相邻音，Ctrl 选两音可跨过中间音符相连；3/5/6/7 连音原地拆分、总时值不变。

小节与反复记号

右栏「小节与段落」插入/删除小节；展开「段落·反复·跳转记号」设置 𝄆𝄇 反复、第一/二段（开口括线）、D.C./D.S./Fine/⊕ Coda、段落线/终止线。点击小节线弹出同款菜单；按住小节线约半秒可独立选中该小节的单个声部，Ctrl+C/V 复制粘贴。

歌词与填词

逐字对位、多段歌词与智能填词。

逐字输入

点歌词行直接打字，Enter/Tab 跳到下一个音。多段歌词（最多 5 段）在左栏「歌词」管理，段序号点击即切换。

智能填词

把整段歌词粘进「智能填词」，自动逐字分配到每个可唱音：自动跳过休止符与连音线延续音；标点跟随前字旁挂、不占对位；- 手动跳过一个音；英文单词整体成词。下方实时预览对齐结果，可点选任意音作为填词起点，「换行对齐乐句」让每行歌词从新小节开始。

💡 一字多音（连音线连接不同音高）会自动只占一个字——melisma 场景不用手动补 -。

排版与打印

出版级排版三步走，预览与导出。

排版面板（顶栏「排版」）

可拖动浮层、实时生效、参数随曲谱保存：

步骤作用
① 基准纸张A5 / A4 / A3，选定后固定——决定每页容量（A3 容纳更多小节与行）
② 智能排版紧凑 / 标准 / 宽松，按出版谱对数时值间距自动缩放行距与间距
③ 手动微调整体缩放（纸张外框不变）、行距（可分选吉他谱·简谱·歌词）、间距；百分比数字点击可输入精确值

内容驱动版式

小节宽度随内容疏密自动伸缩——一拍一个四分音符的小节自然窄于每拍两个八分的小节；每行小节数自由适配，密集小节可独占一行；32 分/三连音逐字带词也能被自动撑开、歌词永不重叠。

打印预览与导出

顶栏「预览」：A5/A4/A3 适配、缩放（±/Ctrl 滚轮/适配/整页）、多页竖排/横排/网格排布；纯净成品谱可直接进入打印。「打印」输出 PDF（浏览器另存为 PDF）或导出高清 PNG；「曲谱反色」仅作用于屏幕浏览，打印自动回到白纸黑字。

播放与练习

真实音色试听与选段循环。

播放控制

空格 或 ▶：点播放、再点暂停、再点继续（音频精确冻结）；⇤ 回到开头并停住。底部混音器可换音色、独奏/静音各声部、调节速度。

选段循环

小节格进度条一格一小节：点击=单小节循环，拖动=选区循环，再点取消；小节多时自动变密集标尺，点 ▦ 打开大格选择面板。

反复记号识别

整曲播放自动按记号走：𝄆𝄇 反复、第一/二段换尾、D.C./D.S. 回跳、Fine 结束、⊕ 跳过中段。

常见问题

还没解决？写信给 support@puyouquan.com。

需要付费吗？

制谱与看谱核心功能免费。后续将推出创作者生态（曲谱发布/收益）与增值服务，届时另行公示。

我的曲谱存在哪里？会丢吗？

当前版本实时保存在你的浏览器本机（localStorage），关掉页面也在；建议定期「导出」.mtab.json 文件备份。云端同步在规划中。

支持手机 / 平板吗？

网页版在平板与手机可打开查看与播放；触控编辑与移动端专属界面在多端规划中。

可以商用我做的谱吗？

你制作的曲谱内容归你；请确保对词曲拥有相应授权。工具内置 SHA-256 时间戳存证辅助确权。

为什么打印出来是白纸黑字，而屏幕上是反色的？

「曲谱反色」是针对屏幕浏览的护眼/投影模式；打印与导出 PDF 时自动回到白纸黑字，省墨且符合成品规范。

音色听起来和真实吉他有差距？

当前使用真实采样＋物理建模混合音色；部署自托管全量音色包后会自动升级，更高保真的合成方案在路线图中。
