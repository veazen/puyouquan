零基础第一课

没学过音乐也能做谱。这一课只讲看懂谱面所需的最少概念，每个概念都对应编辑器里的一个按钮。十分钟读完，后面所有章节都能看懂。

音有多高 —— 简谱的 1–7

简谱用数字 1 2 3 4 5 6 7 表示七个音，唱作 do re mi fa sol la si——就是「哆来咪」。数字上方加一个点表示高八度（更尖），下方加点表示低八度（更沉）；0 表示休止（这一下不出声）。在编辑器里：选中位置按键盘 0–7 就落音，顶栏「8度±」加高低音点。

音有多长 —— 时值

一个音占多长时间叫时值。从长到短：全音符 → 二分音符 → 四分音符 → 八分音符 → 十六分音符，每级都是对半分。简谱里数字下方加横线表示时间减半（一条线=八分，两条=十六分），数字后面跟横线表示延长；音符后加附点 · 表示再延长一半。在编辑器里：顶栏「时值」组选全/2/4/8/16/32 分，「附点」按钮或按 .。

几拍一数 —— 拍号

谱头的 4/4、3/4、6/8 叫拍号：下面的数字说「以几分音符为一拍」，上面的数字说「每小节几拍」。4/4 就是以四分音符为一拍、每小节四拍——流行歌绝大多数是 4/4；3/4 是圆舞曲的「蹦嚓嚓」。竖线把谱面隔成的一格格叫小节。编辑器会自动帮你数拍：某小节的音加起来不够或超了，右栏「信息」页底部的节拍状态会标红，点开有一键修复建议。

什么调 —— 1=C 与变调夹

谱头的 1=C 表示「这首歌的 do 唱 C 这个音高」，换成 1=G 整首歌就整体移高——这叫调。唱不上去就换低一点的调，编辑器顶栏「换调」一键完成，和弦、品位全部自动跟着换。吉他上夹的变调夹（Capo）就是物理换调：夹几品在新建向导里填，谱头会自动标注。

六线谱（TAB）—— 吉他手的地图

六条横线代表吉他的六根弦：最下面一条线是最粗的六弦，最上面是最细的一弦。线上的数字表示按第几品（0=空弦不按），上下对齐的数字表示同时弹。不认识五线谱、不认识简谱都没关系——TAB 直接告诉你手指放哪。在编辑器里：点弦位、敲品位数字即可。

五线谱 —— 三分钟版

五条线上音符位置越高音越高。开头的花体符号叫谱号：𝄞 高音谱号管中高音区（右手/人声/吉他），𝄢 低音谱号管低音区（左手/贝斯）。谱号后面的一排 ♯ 或 ♭ 是调号，再后面是拍号。本编辑器的特色是三种记谱法同源：同一份数据可以切换成简谱看、五线谱看、TAB 看——先用会的记谱法录入，再一键切给需要另一种谱的人。

和弦 —— 字母是什么意思

谱上方的 C、Am、G7 叫和弦标记：几个音一起响做伴奏。大写字母是根音，后缀表示性质——不带后缀是大三和弦（明亮），m 是小三和弦（柔暗），7 是七和弦（想继续走的感觉）。吉他弹唱谱会自动画出和弦图（按法示意图）；不会配和弦可以让编辑器代劳：右栏「创作」页一键配和弦。

读完这一课就可以去「快速上手」做第一首谱了。遇到不认识的名词随时回来查；编辑器里选中任何对象，右栏「创作」页的智能预提示也会实时告诉你当前能做什么。

快速上手

四步做一首谱：建谱 → 录入 → 排版 → 导出。

第 0 步 · 认识界面

打开制谱页是启动台：新建 / 打开 / 导入 / 我的 四个入口。进入编辑后，顶栏是最常用的音符/时值/节奏工具，左栏按图层收纳（歌词/和弦/小节/段落/记号），右栏两个页签——「信息」页是校对中心（曲谱信息、光标位置、节拍状态，更新日志下方标有当前版本号），「创作」页是智能辅助（一键配和弦/配伴奏/智能填词＋随选中对象实时变化的预提示）。

第 1 步 · 按场景建谱

启动台点「新建」，三选一：声乐谱（独唱 / 合唱）、器乐谱（独奏 / 伴奏，含吉他、钢琴等 21 种乐器）、功能谱（级数谱 / 和弦格）——按「我要干什么」选，选完就地展开细项。填标题、调号、拍号、速度即可开始。已有素材不必从零录：向导里还有「导入 MusicXML」「导入 MIDI」两个入口，或从「我的」里选预设改编。

第 2 步 · 录入

录旋律只按数字键：简谱区敲 0–7、TAB 区敲品位数字，落音后光标自动跳到下一个音，一路敲下去即可；需要修改时点谱面任意音符就地改。先落音再点升降号/附点/八度，记号会自动落到刚录的那个音上。填词：选中音符按 Enter 唤出歌词框，打一个字按一次 Enter，逐字对位。标好和弦后，「节奏型库」可按指法一键生成整小节伴奏；钢琴弹唱谱点「伴奏织体」自动生成双手伴奏。

第 3 步 · 排版

顶栏「排版」选基准纸张（A5/A4/A3）与疏密（紧凑/标准/宽松），需要时手动微调缩放与行距；「预览」查看多页成品效果。

第 4 步 · 导出

「打印」弹窗集中全部出口：打印 PDF、高清 PNG、MusicXML、MIDI、分享卡 PNG、互动谱 HTML。所有修改实时自动保存在本机；登录后「保存」进我的曲谱可云端同步。

右栏「信息」页底部的节拍状态实时校验：小节时值与拍号不符会标红，并给出绿色修复建议，一键采纳。
新建、导入都在新窗口打开（顶部页签切换，可多首并排），当前曲谱原样保留；打开已有曲谱会替换当前窗口，有未入库的修改会先弹确认对话，可一键「存入我的曲谱」再继续，不会丢稿。

九种谱类指南

每种场景一节：构成、典型工作流与专属功能。

类型构成适合
吉他弹唱谱六线 TAB＋简谱＋歌词＋和弦图吉他 / 尤克里里弹唱自学与教学
吉他独奏谱TAB＋五线谱联排，电吉他全套技法电吉他 solo、旋律独奏
指弹吉他谱TAB＋五线谱联排，pima 指法/特殊调弦/打板木吉他指弹
钢琴弹唱谱和弦＋伴奏织体自动生成双手（纯伴奏）即兴伴奏、教师考编、幼师
钢琴独奏谱高音＋低音大谱表（右手/左手）钢琴独奏与练习曲
歌谱简谱 1–4 声部＋多段歌词独唱、合唱及二胡/古筝等民乐
教学对照谱五线谱＋简谱行逐列对齐＋歌词音乐课堂、考级教学
器乐五线谱单谱表（高/中/低音谱号可选）器乐独奏、艺考视奏、声部谱
功能谱简谱＋级数和弦；或纯和弦谱乐队排练、即兴伴奏和弦推进

吉他弹唱谱（吉他 / 尤克里里）

三行对齐版式：TAB 点弦位敲品位，简谱与歌词自动同列对齐；输入和弦名自动画和弦图。工作流：标和弦 → 「节奏型库」按指法一键生成整小节伴奏（Shift 跨小节多选可批量套用）→ 补歌词。尤克里里为 4 弦 GCEA，谱表 / 和弦图 / 播放调弦全部自适配。

吉他独奏谱（电吉他）

TAB 上方叠一行标准五线谱（Guitar Pro 式联排），品位自动按调性拼写成五线谱音高，两行始终逐列对齐。电吉他技法齐备：推弦（可标幅度 full/½/¼/1½，支持推弦回放 bend&release 与预推 pre-bend）、摇把、泛音细分（自然/人工/拍泛等）、let ring、点弦、滑音；技法按钮在左栏记号层，选中音符即点即用。

指弹吉他谱（木吉他）

同为联排版式，面向指弹三件套：pima 右手指法（拇指/食/中/无名，标在音符旁）、特殊调弦（Drop D / DADGAD / Open G 等，新建向导里选，TAB 与五线谱换算自动跟随）、打板（低音区/高音区/击板/闷鼓四种，列级标记）。

钢琴弹唱谱

面向即兴伴奏 / 考编的核心工作流：① 标注和弦（或右栏「创作」页「一键配和弦」按功能和声自动建议，已填的小节不覆盖）→ ② 顶栏「伴奏织体」从 21 套按难度分级的织体中选一套（4/4 拍 15 套，2/4、3/4、6/8 各 2 套）（柱式 / 半分解 / 全分解琶音 / 进行曲 / 圆舞曲 / 儿歌伴奏……）→ ③ 自动生成双手伴奏音符——生成的是可编辑真音符，可逐段重生成。主旋律交给演唱者。

钢琴独奏谱

高音＋低音大谱表花括线联排，上下谱表严格纵向对齐、小节线贯穿。和音输入：「和音」按钮输唱名串（如 35 自动向上排列），或在五线谱上 Ctrl+点击直接加音；踏板记号与 1–5 指法数字见「记号大全」。

歌谱

简谱 1–4 声部＋最多 5 段歌词。每个声部可独立切换记谱法：简谱 / 高音谱表 / 低音谱表 / 中音谱表，还可在谱表下附加简谱对照行；合唱分声部、民乐（二胡/古筝等）记谱通用。

教学对照谱

五线谱＋简谱行逐列对齐＋歌词，音乐课堂与考级教学的标配版式。配合「智能配谱」可从一条主旋律一键产出「五线谱＋简谱＋歌词」伴奏教学谱。

器乐五线谱

单谱表出版级刻版，高音 / 中音 / 低音谱号可选，小节内可换谱号；SMuFL/Bravura 真字形、严格系统头部（谱号-调号-拍号）与刻版规则，直接可用于艺考视奏与声部谱。

功能谱

简谱＋级数和弦：级数按调号自动换算（C 调 Am→6m、G/B→5/7），换调级数即时跟随，级数/音名一键切换。「纯和弦谱」模式则渲染为小节格＋节奏斜线，一页纸带乐队排练。

录入与技巧

连续录入、时值节奏、演奏技巧与小节段落。

连续录入 · 落音自动前进

录一段旋律只按音高键：简谱/五线谱敲 0–7、TAB 敲品位数字，落音后光标自动跳到下一个音。三条配套规则：① 先落音、再加记号照常——升降号/附点/八度会自动作用于刚录的那个音；② TAB 两位品位照旧 0.7 秒内连敲两键（如 12 = 12 品）；③ 同列多弦（和弦叠音）按 ← 退回该列再换弦输品位。手动点选谱面即退出连续录入、就地修改。不习惯可在右栏「创作」页预提示里一键关闭，恢复「数字＋→」逐个录。

音符按钮组（顶栏）

按谱类自动切换：简谱=音级 1–7＋休止 0＋高/低八度；五线谱=音名字母 C–B（随调号排列）＋按时值变化的真休止符字形＋♯♭♮；吉他谱=品位 0–9 固定铺开，10 品及以上收在「10–24▾」选择器（尤克里里为 10–15▾），×分解标记分解和弦中不发实音的音。

时值与节奏

顶栏常驻：单时值（QWERT = 全 / 2 / 4 / 8 / 16 分）与常用节奏组合，「更多▾」展开 3/4、6/8 等拍号的节奏选项；「节奏型库」整小节套用，可 Shift 跨小节多选后批量应用（编辑五线谱大谱表时此按钮变为「伴奏织体…」）。变拍子：单个小节可以设置与全曲不同的拍号（小节菜单内），4/4 转 2/4 的过门一格搞定。

附点与双附点

「附点」按钮（或 .）循环：无 → 附点（×1.5）→ 双附点（×1.75）→ 无。加附点时下一音自动减半补拍。按出版规则分档：全 / 2 / 4 / 8 分可双附点，16 分限单附点，32 分不可附点。简谱按国标惯例呈现：附点只画在四分及更短的音上，附点二分记「数字＋2 条增时线」。

音符操作

＋后插 / ＋前插（Insert / Shift+Insert）在任意位置加音符；休止符整列休止；清单音（Backspace）只清当前弦位；拆分 / 合并 / 删音符自由组合——自由编辑优先，不受拍号强制，节拍检查给绿色修复建议。点击音符会弹出快捷浮条：常用操作就近可点，还会按你的操作习惯预判下一步（可关闭）。

演奏技巧（吉他 / 尤克里里）

选中音符点技巧图标：滑弦 S / 击勾弦 H·P / 揉弦 / 泛音 / 点弦 / 闷音 / 无头无尾滑音，S/H/P 自动连线；推弦与跨选连线用 Ctrl 选两音。揉弦波浪线随时值延长；闷音 P.M. 为范围标记。已推弦的音符再点推弦可标注幅度（full / ½ / ¼ / 1½）。扫弦/琶音箭头方向与覆盖弦数都可点谱面调整。

连音线与连音

连音线：单选自动连相邻音，Ctrl 选两音可跨过中间音符相连（跨小节、跨行都会自动断线续画）；3/5/6/7 连音原地拆分、总时值不变。

小节与段落

「小节」面板插入/删除小节；「段落·反复·跳转记号」设置 𝄆𝄇 反复、第一/二段（开口括线）、D.C./D.S./𝄋/Fine/⊕ Coda、段落线/终止线。点击小节线弹出同款菜单；按住小节线约半秒可独立选中该小节的单个声部，Ctrl+点击小节号可多选不连续小节，Ctrl+C/V 复制粘贴。

和弦与级数

和弦弹窗、把位方案与功能谱级数。

输入和弦

选中位置打开和弦弹窗：左列选主音（12 键）、性质（maj/m/7/maj7/sus/add9/dim/aug 等 22 类型全根音可用）与转位（G/B 式斜杠低音）；右列是可编辑和弦图——竖式点格直接点按位，顶部标 ×/○，可拖把位窗。「▶ 试听」按指法自低音弦琶音试听；「把位方案」给出同一和弦的多个把位卡，点选即载入。自定义指法可「保存」进「我的和弦」。

和弦图与移调

一键配和弦

有旋律的谱面在右栏「创作」页点「一键配和弦」：按功能和声自动建议全曲和弦，已填的小节不覆盖；配好后可直接接「伴奏织体」或「一键配伴奏」。

功能谱级数

选中音符点「和弦/级数」：以级数为主构建（级数 × 类型扩展 × 转位低音），本调常用库＋最近使用一键选用，支持调外和弦；谱面按 1=调号 显示级数，级数/音名一键切换，点击标注可再编辑，换调级数即时跟随。

歌词与填词

逐字对位、多段歌词与智能填词。

逐字输入

选中要填词的音符，按 Enter 唤出歌词输入框：打一个字、按一次 Enter（或 Tab）跳到下一个音，一路「字—回车—字—回车」逐字对位；Esc 结束。多段歌词（最多 5 段）在左栏「歌词」层管理，段序号点击即切换，正在编辑第几段谱面会高亮。

智能填词

整段歌词一次搞定：右栏「创作」页「智能填词」，把整段歌词粘进去，自动逐字分配到每个可唱音——自动跳过休止符与连音线延续音；标点跟随前字旁挂、不占对位；- 手动跳过一个音；英文单词整体成词。下方实时预览对齐结果，可点选任意音作为填词起点，「换行对齐乐句」让每行歌词从新小节开始。

一字多音（连音线连接不同音高）会自动只占一个字——melisma 场景不用手动补 -。

步骤作用

播放与跟练

播放控制

节拍器与倍速

选段循环

小节格进度条一格一小节：点击=单小节循环，拖动=选区循环，再点取消；小节多时自动变密集标尺，点 ▦ 打开大格选择面板精确框选。

专业制谱之路

从「能做出谱」到「做出可出版、可教学、可交付的谱」——校对方法、刻版常识与协作工作流。

三关校对法

交付前把每首谱过三关：① 节拍关——右栏「信息」页底部节拍状态必须全绿，红的小节点开逐条采纳修复建议（或手动改时值）；② 听觉关——按 空格 从头试听一遍，耳朵抓错音比眼睛快得多，错音处点谱面直接改；③ 成品关——顶栏「预览」逐页检查：标题作者是否齐全、翻页处是否断在乐句中间、歌词是否有挤压。三关全过再导出。

引擎替你保证的刻版细节

这些出版级细节不需要你操心，但知道它们存在有助于判断谱面对不对：SMuFL/Bravura 标准音乐字形；系统头部严格按「谱号-调号-拍号」顺序；大谱表小节线上下贯穿、花括线连接；符杠按拍组自动分组（复合拍号按 6/8 的三三分组）；音符间距按时值对数分配（出版谱惯例：二分音符占的横向空间约为四分音符的 1.4 倍而非 2 倍）；变音记号小节内自动进位省略。若谱面出现不符合这些规则的地方，多半是数据录错了而不是排版问题。

高效工作流（建议顺序）

旋律 → 和弦 → 织体/伴奏 → 歌词 → 记号 → 排版。先把旋律骨架敲完（连续录入一路数字键），再标和弦（或一键配和弦打底、人工润色），然后生成/录入伴奏声部，歌词用智能填词整段灌入，表情记号最后统一加——这个顺序返工最少。修改高发区用 Ctrl+C/V 复制相似小节再改差异，比逐音重录快。

与专业软件协作

把这里当作快速录入与中文场景排版的前台，MuseScore/Finale 当作西文出版后台：本编辑器录完导出 MusicXML 到专业软件做西文出版细节；反过来 AI 转谱、MuseScore 的工程也能导入进来做简谱化、加歌词、出教学对照谱——这是专业软件不擅长的。记号、附点、变音拼写、TAB 弦品在两个方向都保持一致。

常见错谱清单（交付前自查）

症状原因与修法
节拍状态标红小节时值与拍号不符——点开红字逐条采纳建议；过门小节该用「变拍子」而不是硬凑
唱着别扭、音对谱不对八度点漏标——简谱检查高低音点，五线谱检查是否该用 8va 而不是满谱加线

发布与确权

登录后「保存」进我的曲谱（云端同步），「发布」提交到谱库生成分享页；个人中心提供 SHA-256 时间戳存证辅助确权。对外交付优先给互动谱 HTML（对方免安装、可播放移调）或打印 PDF（正式场合）。

练手路线建议：先用「我的」里的预设曲谱各谱类改编一首 → 再从零做一首完整弹唱谱（旋律+和弦+歌词）→ 最后挑战一首钢琴弹唱谱（配和弦+织体生成+精修）。三首做完，九种谱类就都不在话下了。

常见问题

还没解决？写信给 support@puyouquan.com。

需要付费吗？

制谱核心功能免费使用。会员提供增值权益（详见应用内「会员」入口），支持微信支付开通。

我的曲谱存在哪里？会丢吗？

编辑中的修改实时保存在浏览器本机（localStorage），关掉页面也在；「保存」进我的曲谱后，登录用户自动云端同步，换设备登录即可取回。重要作品仍建议 Ctrl+S 导出 .mtab.json 双保险。

怎么同时管理多首曲谱？

可以多开：新建、导入都在新窗口打开，顶部页签切换；做好的谱「保存」进「我的曲谱」，随时打开继续编辑。打开已有曲谱会替换当前窗口，有未入库修改时会先弹确认对话（可一键存入再继续），不会丢稿。

录入时怎么光标自己往前跳？

这是「落音自动前进」：录旋律只按音高键即可，不必再按方向键。先落音再点升降号/附点仍作用于刚录的音；TAB 两位品位连敲两键照常。不习惯可在右栏「创作」页预提示里一键关闭。

AI 转谱 / MuseScore 的文件能用吗？

能。启动台「导入」或新建向导里「导入 MusicXML」直接读入；MIDI 也可导入并自动量化。成品同样能导出 MusicXML/MIDI 回到专业软件——记号、附点、TAB 弦品等往返一致。

支持手机 / 平板吗？

谱库观看与互动谱在手机上已适配（自动缩放到屏宽、可播放移调）；编辑建议在电脑或大屏平板上进行，移动端专属编辑界面在多端规划中。

我用的是不是最新版本？

编辑器右栏「信息」页「更新日志」下方标有当前版本号。若与更新公告不符，按 Ctrl+F5（Mac：Cmd+Shift+R）强制刷新即可获取新版。

可以商用我做的谱吗？

你制作的曲谱内容归你；请确保对词曲拥有相应授权。工具内置 SHA-256 时间戳存证辅助确权。

为什么打印出来是白纸黑字，而屏幕上是反色的？

「曲谱反色」是针对屏幕浏览的护眼/投影模式；打印与导出 PDF 时自动回到白纸黑字，省墨且符合成品规范。

音色听起来和真实吉他有差距？

当前使用真实采样＋物理建模混合音色；部署自托管全量音色包后会自动升级，更高保真的合成方案在路线图中。
