# Muse 吉他谱软件分析报告

## 一、上传文件的逆向分析结论

分析对象：`Muse_____101_2192641.exe`（3,180,856 字节）

### 1. 这个文件不是 Muse 软件本体

对 PE 结构、节区、导入表、内嵌字符串和文件尾部数据的分析表明，
**这是一个下载站的"高速下载器"外壳程序，而不是 Muse 吉他谱软件本身**：

| 证据 | 内容 |
|------|------|
| 调试符号路径 | `D:\Develop\2026\winToolBoxSetup\temp\Link\UIDownloader\Release\setup.pdb` —— 工程名为 **UIDownloader（界面下载器）**，2026 年编译，而 Muse 是 2000 年代初的老软件 |
| 源码路径残留 | `uidownloader\config.cpp`、`uidownloader\dialogs\downloadframe.cpp`（下载配置、下载进度对话框） |
| 导入的系统库 | `WINHTTP.dll`、`WS2_32.dll`、`IPHLPAPI.DLL`、`CRYPT32.dll` —— 联网下载所需，一个单机制谱软件不需要这些 |
| 内嵌解压引擎 | 7-Zip / RAR1-RAR5 / zlib 解压器的完整类名（`NCompress::NRar3::CDecoder` 等），用于解开下载回来的压缩包 |
| 网络协议栈 | 内含 libcurl 风格的字符串（RTSP、SASL、Winsock 等） |
| 文件尾部附加数据 | 仅为 13KB 的 Authenticode 数字签名（DigiCert 证书链），**不含任何被打包的软件本体** |
| 文件名特征 | `Muse_____101_2192641.exe` 中的数字是下载站的资源 ID，由服务器按资源动态改名 |

### 2. 工作原理与风险提示

这类下载器运行后会联网向下载站服务器请求真正的安装包地址，同时常常
**捆绑推广软件**（安装页面上预勾选的"全家桶"）。建议：

- 不要在真实环境直接运行它；
- 若要获得原版 Muse，请从可信的老软件归档站获取"绿色版/原版"压缩包，
  并核对文件哈希；
- 原版 Muse 是绿色单文件程序（数百 KB 到几 MB），不需要联网安装。

由于该文件不含 Muse 程序本体，无法从中提取 Muse 的排版引擎与文件格式；
下文对 Muse 的功能总结基于其公开、广为人知的产品形态。

## 二、Muse 的设计理念（新软件的继承目标）

Muse 之所以在国内吉他爱好者中口碑极好，核心在于它精准贴合了中国人的
读谱习惯，这也是国外软件（Guitar Pro、MuseScore 等）至今做得不好的地方：

1. **简谱 + 六线谱 + 歌词三行绑定**：同一时刻的音，简谱数字、六线谱品位、
   歌词字三者严格上下对齐，弹唱时"看一列就够了"。
2. **以"列"为时间单位**：编辑的基本对象是一个时间列（可含多根弦的按法），
   而不是抽象的音符对象，输入直观。
3. **简谱自动推导**：在六线谱上写品位数字，简谱行按调号自动算出唱名
   （1=C、1=G……），不用重复输入。
4. **和弦名 + 和弦图**：小节上方标和弦名，曲首列出用到的和弦指法图。
5. **一键播放试听**：用 MIDI 试听自己打的谱，检查节奏音高。
6. **排版即打印**：所见即所得，直接打印成纸质谱。

## 三、新时代方案：MuseTab（本仓库 `muse-tab/`）

用现代 Web 技术复刻并升级上述理念，做到 **零安装、跨平台（Windows /
macOS / Linux / 手机平板浏览器）、单文件、离线可用**：

| Muse 的理念 | MuseTab 的实现 |
|------|------|
| 简谱+六线谱+歌词三行对齐 | SVG 排版引擎，和弦行/简谱行/六线谱/歌词行按时间列严格对齐，自动换行分行 |
| 以列为单位编辑 | 点击六线谱任意弦位直接键入品位数字（支持两位数），方向键在列/弦间移动 |
| 简谱自动推导 | 根据调号（1=C…1=B）、变调夹位置从品位自动算出简谱数字、高低音点、时值减时线与延音线 |
| 和弦支持 | 内置常用和弦指法库，小节上方标注和弦名，曲首自动生成和弦图一览 |
| 播放试听 | Web Audio 合成（Karplus-Strong 拨弦算法，音色接近真实吉他），播放时高亮当前列 |
| 打印 | 浏览器打印/另存 PDF，打印样式自动隐藏工具栏 |
| 存档 | 自动保存到浏览器本地；可导出/导入 `.mtab.json` 曲谱文件 |
| 升级点 | 歌词批量填词（整段歌词一键按列分配）、撤销/重做、深色模式 |

### 使用方式

直接用浏览器打开 `muse-tab/index.html` 即可，无需安装任何东西。
详细操作见应用内"帮助"按钮。

## 四、v2 增补：对照真实 Muse 成品谱的深度分析

对一份 Muse 制作的《搁浅》弹唱谱成品的版面分析，确认了 Muse 弹唱谱的
核心版面逻辑，并据此重构了 MuseTab：

| 参考谱中观察到的 Muse 逻辑 | MuseTab v2 实现 |
|------|------|
| 六线谱与简谱是**两个独立声部**：TAB 记吉他伴奏指法，简谱记人声旋律，节奏各自独立、按小节对齐 | 数据模型改为每小节 `tab[]` + `vox[]` 双列流，排版引擎按小节对齐、声部内按时值比例分布 |
| 和弦图随行显示在每个和弦变化点上方（含横按、把位数字） | 随行和弦图模式（可切换曲首集中/隐藏） |
| TAB 音符下方有符干，同拍八分/十六分连符杠 | 符干 + 同拍符杠自动分组 |
| × 记号（切音/闷音）、扫弦箭头、琶音波浪线 | 全部支持，播放时切音发噪声打击声、扫弦有扫拂时差 |
| 简谱减时线同拍连体、连音线弧线、高低八度点、升降号、延长线 – | 全部支持，连音线播放时自动延长 |
| 反复记号 |: :|、小节号、左上 1=G 与拍号分数式、右上作词/作曲/制谱 | 全部支持 |

## 五、v3 增补：侧边栏工作台与多声部

按用户需求完成的第三轮整改：

1. **左侧边栏**：所有功能按键移入左栏，分为吉他谱 / 简谱 / 歌词三大板块，
   另有文件、播放、小节、节拍检查、显示与帮助分区。
2. **多声部**：吉他谱与简谱板块各支持最多 5 个声部（吉他1–5、旋律1–5），
   歌词支持最多 5 段（每段独立填写/清空/批量填词）。
3. **常用节奏型**：吉他板块 8 种（分解、柱式、根音、民谣扫弦、八分扫弦、
   切音律动、琶音），简谱板块 7 种（四分、二分、全音、八分、前八后十六、
   附点、大切分）；支持 Shift 跨小节多选后一键批量套用；吉他节奏型在有
   和弦时按和弦指法自动生成音符。
4. **节拍自动校验**：以拍号为准逐小节逐声部核对时值总和，不符的小节谱面
   标红加 ⚠，左栏"节拍检查"实时列出错误（点击跳转定位）。
5. **扫弦修正**：扫弦箭头/琶音波浪线只跨该列实际弹奏的弦，不再固定六根弦。

## 六、v4 增补：Ribbon 工作台与图示化节奏型库

针对"侧边栏显示不全"的反馈与教材节奏型图参考完成的第四轮整改：

1. **顶部 Ribbon 分页工具栏**：文件/撤销/播放等常驻主栏；吉他谱、简谱、
   歌词、小节四个分页，点击谱面自动切换到对应分页，解决边栏纵向放不下的问题。
2. **时值组独立共用**：单时值与组合时值两组从三大板块抽出，在吉他谱/简谱
   分页均显示；组合时值支持把当前音一键拆分为前八后十六、十六×4 等组合。
3. **图示化时值/节奏型**：所有时值按钮与节奏型卡片均用 SVG 音符图示
   （×符头、符干、同拍符杠、∧∨扫弦方向、附点、休止符）+ 文字描述 + 拍数，
   风格对齐经典吉他教材的节奏型图例。
4. **节奏型扩容**：吉他库 24 种分四类（分解 2/4·4/4、分解 3/4·6/8、
   扫弦 2/4·4/4、扫弦 3/4），新增交替低音、前八后十六分解、十六分流水、
   琶音收尾、放克切音、慢摇滚等；简谱库 17 种分三类；均支持 Shift 多选
   小节批量套用与按和弦指法自动生成。
5. **节拍检查**移至工具栏下状态条，实时汇总、点击展开定位。

## 七、v5 增补：智能编辑与教材式记谱

第五轮整改（用户五项需求逐项落实）：

1. **拖动多选 + 自动补齐**：按住左键拖动即可在同声部内跨小节多选（Shift+
   点击亦可）；多选后替换时值/附点会自动按拍号补充或删减音符——扫弦小节
   补交替方向的扫弦箭头、分解小节按和弦指法补分解音、简谱补休止符；多选
   加连音线一键成链；"小节"页另有"补齐小节时值"按钮可修复所有声部。
2. **和弦节奏型预提示**：在和弦框输入新和弦、或点击谱面上的和弦图，弹出
   预提示条推荐常用节奏型（含图示），一键插入或打开节奏型库；简谱页的
   快捷节奏型按用户要求删减，仅保留库入口（时值/组合时值已覆盖）。
3. **逐拍对齐**：排版引擎改为时间网格制——同一小节内吉他谱与简谱按拍数
   比例共用同一横轴，四分音符宽度恰为八分音符两倍、起点对齐。
4. **教材式 × 记谱**：分解伴奏中和弦内音显示 ×（记谱:× 模式，可切回全
   数字），只有和弦外音显示品位数字；更换和弦时自动按新指法重排本小节
   分解/扫弦音（如 C 根音 5弦3品 → G 根音自动落 6弦3品）。
5. **扫弦纯箭头**：扫弦列不再画品位，只画箭头且只落在需要扫的弦上；
   "箭头−/箭头＋"可编辑箭头长短（覆盖弦数），播放同步只扫覆盖的弦。

## 八、v6 增补：拍对齐修复与吉他技法

第六轮整改（用户四项）：

1. **逐拍严格对齐 + 时值可见**：排版由"列中心定位"改为"拍点左对齐"——
   每拍/每音以其起始拍数定位，四分音符与八分音符的每拍第一个音在吉他谱
   与简谱里像素级对齐、宽度按时值统一。吉他谱空列（无音符无扫弦）现在
   显示休止符，避免"看不见的列"导致的"四个四分却报错"困惑；节拍识别
   经验证准确。
2. **和弦图方向修正**：改为六弦在左、一弦在右（标准吉他和弦图朝向）。
3. **弦位光标**：鼠标悬停六线谱任一弦位显示高亮光标框，点击定位更直观。
4. **扫弦弦数选择**：点击扫弦列弹出菜单选择覆盖 2–6 根弦（箭头长短），
   与工具栏"箭头−/＋"等效。
5. **Ctrl 多选音符 + 技法**：按住 Ctrl 点选多个音符（高亮圈选），弹出技法
   预提示条，可添加滑弦(sl)/击弦(h)/勾弦(p)/推弦(b)/揉弦(~)，谱面以连线
   加符号标注（新增技法功能）。
6. 打开即自动保存（persist on init）。

## 九、v7 增补：排版两端对齐与交互精修

第七轮整改（用户四项）：

1. **每行总宽两端对齐**：所有行拉伸至统一宽度（末行不足 55% 时保持自然
   宽度），右端小节线整齐对齐。
2. **技法连线头对头**：滑弦/击弦/勾弦等连线改为从被选中音符的符头连到
   下一个被选中音符的符头（可跨列、跨弦），标注技法缩写。
3. **扫弦所见即所得**：功能栏"扫↓"谱面箭头即向下、"扫↑"即向上；点击
   扫弦箭头的弹出菜单支持双向锚点——覆盖弦数可"从6弦向上"也可"从1弦
   向下"选择。
4. **功能栏瘦身**：吉他谱页收起组合时值组（位置让给和弦功能）；简谱页
   时值默认只显示前四个（全/2分/4分/8分），其余与组合时值折叠在"更多▾"
   里；两页均不再出现横向滚动条。
