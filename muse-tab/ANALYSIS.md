# Muse 吉他谱软件分析报告

## 一、上传文件的逆向分析结论

分析对象：`Muse_____101_2192641.exe`（3,180,856 字节）

### 1. 这个文件不是 Muse 软件本体

对 PE 结构、节区、导入表、内嵌字符串和文件尾部数据的分析表明，
**这是一个下载站的"高速下载器"外壳程序，而不是 Muse 吉他谱软件本身**：

| 证据 | 内容 |
|------|------|
| 调试符号路径 | `D:\Develop\2026\winToolBoxSetup\temp\Link\UIDownloader\Release\setup.pdb` —— 工程名为 **UIDownloader（界面下载器）**，2026 年编译，而 Muse 是 2000 年代初的老软件 |
| 源码路径残留 | `uidownloader\config.cpp`、`uidownloader\dialogs\downloadframe.cpp`（下载配置、下载进度对话框） |
| 导入的系统库 | `WINHTTP.dll`、`WS2_32.dll`、`IPHLPAPI.DLL`、`CRYPT32.dll` —— 联网下载所需，一个单机制谱软件不需要这些 |
| 内嵌解压引擎 | 7-Zip / RAR1-RAR5 / zlib 解压器的完整类名（`NCompress::NRar3::CDecoder` 等），用于解开下载回来的压缩包 |
| 网络协议栈 | 内含 libcurl 风格的字符串（RTSP、SASL、Winsock 等） |
| 文件尾部附加数据 | 仅为 13KB 的 Authenticode 数字签名（DigiCert 证书链），**不含任何被打包的软件本体** |
| 文件名特征 | `Muse_____101_2192641.exe` 中的数字是下载站的资源 ID，由服务器按资源动态改名 |

### 2. 工作原理与风险提示

这类下载器运行后会联网向下载站服务器请求真正的安装包地址，同时常常
**捆绑推广软件**（安装页面上预勾选的"全家桶"）。建议：

- 不要在真实环境直接运行它；
- 若要获得原版 Muse，请从可信的老软件归档站获取"绿色版/原版"压缩包，
  并核对文件哈希；
- 原版 Muse 是绿色单文件程序（数百 KB 到几 MB），不需要联网安装。

由于该文件不含 Muse 程序本体，无法从中提取 Muse 的排版引擎与文件格式；
下文对 Muse 的功能总结基于其公开、广为人知的产品形态。

## 二、Muse 的设计理念（新软件的继承目标）

Muse 之所以在国内吉他爱好者中口碑极好，核心在于它精准贴合了中国人的
读谱习惯，这也是国外软件（Guitar Pro、MuseScore 等）至今做得不好的地方：

1. **简谱 + 六线谱 + 歌词三行绑定**：同一时刻的音，简谱数字、六线谱品位、
   歌词字三者严格上下对齐，弹唱时"看一列就够了"。
2. **以"列"为时间单位**：编辑的基本对象是一个时间列（可含多根弦的按法），
   而不是抽象的音符对象，输入直观。
3. **简谱自动推导**：在六线谱上写品位数字，简谱行按调号自动算出唱名
   （1=C、1=G……），不用重复输入。
4. **和弦名 + 和弦图**：小节上方标和弦名，曲首列出用到的和弦指法图。
5. **一键播放试听**：用 MIDI 试听自己打的谱，检查节奏音高。
6. **排版即打印**：所见即所得，直接打印成纸质谱。

## 三、新时代方案：MuseTab（本仓库 `muse-tab/`）

用现代 Web 技术复刻并升级上述理念，做到 **零安装、跨平台（Windows /
macOS / Linux / 手机平板浏览器）、单文件、离线可用**：

| Muse 的理念 | MuseTab 的实现 |
|------|------|
| 简谱+六线谱+歌词三行对齐 | SVG 排版引擎，和弦行/简谱行/六线谱/歌词行按时间列严格对齐，自动换行分行 |
| 以列为单位编辑 | 点击六线谱任意弦位直接键入品位数字（支持两位数），方向键在列/弦间移动 |
| 简谱自动推导 | 根据调号（1=C…1=B）、变调夹位置从品位自动算出简谱数字、高低音点、时值减时线与延音线 |
| 和弦支持 | 内置常用和弦指法库，小节上方标注和弦名，曲首自动生成和弦图一览 |
| 播放试听 | Web Audio 合成（Karplus-Strong 拨弦算法，音色接近真实吉他），播放时高亮当前列 |
| 打印 | 浏览器打印/另存 PDF，打印样式自动隐藏工具栏 |
| 存档 | 自动保存到浏览器本地；可导出/导入 `.mtab.json` 曲谱文件 |
| 升级点 | 歌词批量填词（整段歌词一键按列分配）、撤销/重做、深色模式 |

### 使用方式

直接用浏览器打开 `muse-tab/index.html` 即可，无需安装任何东西。
详细操作见应用内"帮助"按钮。
