# 谱友圈 · 设计规范与多端规划 v1（v34.71 起生效）

> 本文档约束谱友圈全产品线（网页版编辑器、谱友圈、创作者中心、后续各客户端）的
> 品牌、视觉与功能架构，新功能开发须遵循本规范。

## 二、设计语言（极简现代 / Apple 风）

原则：**简洁、耐看、实用**。中性底色承载内容，色彩只用于表达"可交互/选中/危险"；
层级靠留白、发丝线与柔和阴影，不靠重边框和渐变。

### 设计令牌（CSS 变量，:root 中定义）

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `--bg` | `#f5f5f7` | `#161618` | 页面底色（中性灰） |
| `--panel` | `#ffffff` | `#1f1f21` | 卡片/面板/弹窗表面 |
| `--text` | `#1d1d1f` | `#f5f5f7` | 主文字（近黑/近白） |
| `--muted` | `#6e6e73` | `#98989d` | 次要文字 |
| `--border` | `rgba(0,0,0,.11)` | `rgba(255,255,255,.16)` | 控件描边（发丝线） |
| `--border-soft` | `rgba(0,0,0,.06)` | `rgba(255,255,255,.08)` | 分隔线/卡片描边 |
| `--accent` | `#0071e3` | `#0a84ff` | 系统蓝：主按钮/选中/链接 |
| `--accent-soft` | 蓝 10% | 蓝 17% | 选中底色/聚焦光环 |
| `--hover` | 黑 4.5% | 白 6% | 中性悬停底色 |
| `--glass` | `rgba(251,251,253,.82)` | `rgba(24,24,26,.78)` | 毛玻璃表面（配 blur） |
| `--danger / --ok` | `#e8362b / #1d9a53` | `#ff453a / #30d158` | 危险/成功 |
| `--radius` | `10px` | 同 | 基准圆角 |

### 组件规范

- **顶栏 / 播放条**：毛玻璃（`--glass` + `backdrop-filter: blur(20px) saturate(1.8)`），
  下缘/描边用 `--border-soft`。
- **按钮**：白底发丝线、圆角 8px；悬停为中性 `--hover` 底色（不变色不描蓝）；
  按下轻微缩放（`scale(.985)`）。**主按钮**为系统蓝**胶囊**（`border-radius:980px`）。
- **选中态**：蓝色允许出现在"选中/激活"（`.on`、`.primary`、光标、循环选区）。
- **卡片**：`--panel` 白面 + `--border-soft` 描边 + 轻投影；悬停加深投影+上浮 1–2px，
  不改边框颜色。圆角 13–16px（越大的容器圆角越大）。
- **弹窗**：圆角 18px，遮罩 `rgba(0,0,0,.34)` + `blur(7px)`，大投影。
- **字体**：系统字体优先 `-apple-system / PingFang SC / HarmonyOS Sans SC / Noto Sans SC`。
- **禁止**：渐变按钮、彩色重投影、3px 以上实色边框、无意义图标堆砌。

## 三、多端功能编排规划

### 架构分层（为客户端化预留）

```
┌─ 平台外壳（每端一套）────────────────────────────┐
│  Web(现在) / 桌面(Tauri|Electron) / 平板 / 手机 / 小程序 │
├─ UI 组件层（设计令牌驱动，本文档第二节）─────────┤
├─ 领域核心（平台无关，可独立打包）────────────────┤
│  · 数据模型（song v3 JSON，PYQ-FORMAT.md）          │
│  · 谱面渲染引擎（SVG，纯函数：song → SVG）          │
│  · 播放引擎（WebAudio：采样+合成、反复记号导航）    │
│  · 校验/移调/和弦库等音乐逻辑                        │
└─ 数据层：localStorage(现在) → 云端 API（Phase 1）──┘
```

现单文件内已接近此分层（render/audio/model 职责分离）；客户端化时第一步是把
"领域核心"抽成独立 JS 模块包，各端外壳复用。**新功能一律写进核心层，不写死在
Web 外壳里**（例如不直接依赖鼠标事件/窗口尺寸，交互入口由外壳适配）。

### 端定位与功能矩阵

| 端 | 定位 | 功能范围 |
|---|---|---|
| **Web/桌面** | 创作主力 | 全功能编辑、多窗口、发布、创作者中心、平台管理 |
| **平板** | 创作+演奏 | 编辑（触控优化+悬浮辅助键盘）、谱架模式（全屏/自动卷谱/脚踏翻页） |
| **手机** | 查看+轻编辑 | 谱友圈消费、播放跟谱、移调查看、歌词/和弦微调、分享 |
| **小程序** | C端消费 | 谱友圈浏览/购买/收藏、观看模式（只读+播放+移调），零编辑 |

### 交互适配约定

- **导航模型**：桌面=顶栏+左右坞；平板=顶栏+可收起侧板；手机/小程序=底部 Tab
  （谱友圈 / 我的曲谱 / 播放 / 我）。同一功能各端入口位置可变、语义与图标不变。
- **断点**：≥1200px 三栏（现网页版）；768–1200px 隐藏右坞、左坞变浮层；
  <768px 单栏+底部 Tab（观看优先，编辑降级为"横屏建议"）。
- **触控**：所有可点目标 ≥40×40pt；谱面小节线/音符命中区已按此放宽，继续保持。
- **数据**：`musetab-*` localStorage 键名永久不变；云端上线后以"本地缓存+同步"
  模式兼容离线，格式即 PYQ-FORMAT.md。
