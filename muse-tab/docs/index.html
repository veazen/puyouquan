谱友圈 · 使用文档

在线制谱工具：吉他六线谱、尤克里里谱、简谱、功能谱的制作、试听、打印与分享。无需安装，打开网页即用，作品自动保存在本机。

快速上手（3 步做一首谱）

  1. 新建曲谱：点「新建」选择曲谱类型——吉他谱 / 尤克里里谱 / 简谱 / 功能谱，填入标题、词曲作者、拍号、变调夹与预设小节数；也可在「曲谱库」里打开预设曲谱改编。
  2. 录入音符：六线谱区点弦位、敲品位数字 0–24；简谱区点数字位、敲 0–7；点歌词行直接打字。有和弦时用「节奏型库」一键按指法生成整小节。
  3. 润色与试听：用编辑栏改时值/节奏、加连音线、倚音、演奏技巧、力度记号；空格试听，选中小节格可循环练习；「打印 / 导出」输出 A4。所有修改实时自动保存。

曲谱类型

🎸 吉他谱（六线谱）六线 TAB ＋ 简谱 ＋ 歌词三行对齐，标准弹唱谱版式，支持和弦图、演奏技巧与扫弦琶音记号。
🎻 尤克里里谱四线 TAB（GCEA 标准调弦）＋ 简谱 ＋ 歌词，与吉他谱同一套编辑方式与技巧体系，配尤克里里专属和弦图。
🎵 简谱纯简谱 ＋ 歌词，不含 TAB 行，适合旋律记谱、声乐与教学；支持八度点、升降还原号、倚音、波音等。
🎹 功能谱乐队排练常用：简谱 ＋ 级数和弦标注，按 1=调号自动换算（C 调 Am → 6m），支持转位与扩展和弦。

录入与编辑

音符与时值

顶部编辑栏常驻「时值 / 节奏 / 记号 / 音符」四组。单时值可用 QWERT 快捷切换，「附点」自动把相邻音配成一半时值，「节奏型库」整小节套用常见分解与扫弦型。

自由编辑

任意位置可前插 / 后插（Insert）、拆分、合并、删除音符；不受拍号强制，节拍不符会自动标红并在「节拍检查」给出一键修复建议。吉他谱可加休止符（按时值显示 𝄽𝄾𝄿 等符号），Backspace 只清当前弦位。

连音线与技巧

连音线单选自动连相邻音，Ctrl 选两音可跨过中间音符相连；3/5/6/7 连音原地拆分、总时值不变。吉他谱演奏技巧含滑弦、击弦、勾弦、推弦、揉弦、泛音、点弦、闷音，S/H/P 自动连线。

和弦与级数

吉他谱输入和弦会自动生成和弦图并按指法重排，改和弦时智能移调；「和弦编辑器」支持模拟指板自选音符创建自定义和弦并保存为用户和弦。

功能谱级数和弦

功能谱以级数为主构建和弦：级数 1–7（含调内默认性质与本调音名提示）× 类型/扩展（三和弦、七和弦、6/9/11/13 等）× 转位斜杠低音 /1–/7，点选即时应用；支持自定义后缀与调外和弦。谱面可一键在「级数 ↔ 音名」间切换显示，换调即时跟随。

播放与谱架

底部播放条支持播放 / 暂停 / 从头 / 停止；混音器可为每条声部换音色、独奏、静音、调音量与速度。播放自动识别反复记号（𝄆𝄇、第一/二段、D.C./D.S./Fine/⊕ Coda）。

音色

核心乐器（木吉他 / 尼龙吉他 / 贝斯 / 钢琴）内置真实录音采样，播放采用「逐弦延音」发声模型——同一根弦被再次弹响才掐断旧音，不同弦的音自然叠加延续，接近真实吉他的听感。「🎧 高保真」开关控制采样音色，部署自托管音色包后可升级到全音域采样。

谱架模式与移调

观看曲谱时可即时移调（♯/♭ 或 +/− 升降半音，调号、和弦、简谱旋律同步移调，非破坏性）；「🎼 谱架」进入全屏沉浸模式，配自动卷谱（可调速、到谱尾自动停），适合看谱演奏。

简谱乐理小知识

为方便新手，这里补充制谱常用的基础乐理。

简谱是什么

简谱用数字 1 2 3 4 5 6 7 表示音阶中的 do re mi fa sol la si（唱名），是可动 do 记谱法：数字表示相对音级，实际音高由调号（1=X）决定。例如「1=C」时 1 是 C，「1=G」时 1 是 G。因此简谱换调只需改调号，旋律数字不变。

音的高低与时值

  • 八度点：数字上方加点表示高八度，下方加点表示低八度，可叠加。
  • 时值：数字本身为四分音符；下加一横线为八分音符、两横线为十六分音符；数字后加「-」为增时线（延长一拍），加「.」为附点（延长一半）。
  • 升降还原：数字前 ♯ 升半音、♭ 降半音、♮ 还原。

和弦功能与级数

流行音乐常用级数标记和弦进行：把调内七个音级用罗马数字或阿拉伯数字表示，1（主）、4（下属）、5（属）是三大功能和弦，6m（关系小调）也极常用。经典进行如「1–5–6m–4」在任何调都通用——这正是功能谱的价值：记录框架，乐手按级数即兴。谱友圈的功能谱可在级数与具体音名之间一键切换。

导出与分享

  • 打印 / PDF：选择纸张尺寸后打印，在打印对话框选「另存为 PDF」即可导出，自动 A4 分页。
  • PNG 长图：一键导出高清图片，便于发朋友圈或群里分享。
  • 曲谱文件：Ctrl+S 导出曲谱数据文件，可在其他设备打开继续编辑。
  • 多窗口：标签栏可同时打开多首不同类型的曲谱，保存状态一目了然。

常见问题

我的曲谱保存在哪里？会丢吗？
曲谱默认保存在你当前浏览器的本地存储中，实时自动保存。请勿在编辑重要曲谱后清除浏览器数据；建议定期用「导出曲谱文件」备份，或在多设备使用。
播放没声音怎么办？
请先点页面任意处或播放按钮（浏览器要求用户交互后才能出声）；确认没有静音、音量正常，且对应声部未被静音。
为什么手机上编辑不太方便？
手机端已适配为查看与轻编辑优先，谱面自动缩放、功能面板收为底部抽屉。完整制谱建议用电脑或平板横屏。
可以导出给别人打印吗？
可以。用「打印 / 导出」选 A4 打印或另存 PDF，也可导出 PNG 长图分享。
支持哪些乐器音色？
木吉他、尼龙吉他、尤克里里、电吉他、贝斯、钢琴、电钢、八音盒、弦乐、长笛、人声等；核心乐器为真实录音采样。
