# MuseTab —— 新时代的中文吉他谱编辑器

向经典国产吉他谱软件 **Muse** 致敬的现代 Web 复刻：简谱 + 六线谱 + 歌词
三行严格时间对齐，符合中国吉他爱好者的读谱与制谱习惯。

**零安装**：用任何现代浏览器打开 [`index.html`](index.html) 即可使用，
单文件、离线可用、跨平台（Windows / macOS / Linux / 手机平板）。

## 功能（v2 弹唱双声部版）

- **双声部弹唱谱结构**（与经典 Muse 弹唱谱一致）：上区六线谱 = 吉他伴奏，
  下区简谱 = 人声旋律 + 歌词，两声部节奏各自独立、按小节自动对齐
- **伴奏声部**：点弦位键入品位（0–24）、× 切音/闷音、扫弦箭头（↓↑）、
  琶音波浪线、符干与同拍符杠（八分/十六分自动连桥）
- **旋律声部**：直接键入唱名 0–7、升降号、高低八度点、附点、
  同拍连体减时线、延音线（–）、连音线（播放时自动延长）
- **和弦**：内置指法库自动补全，和弦图可切换随行显示（每个和弦变化点
  上方画图，如 Muse）/ 曲首集中 / 隐藏
- **反复记号** `|:` `:|`、小节号、左上 `1=X 拍号 速度`、右上作词/作曲/制谱
- **批量填词**：整段歌词一键按音分配，标点自动跟随
- **播放试听**：伴奏用 Karplus-Strong 拨弦合成（扫弦/琶音有扫拂时差、
  切音为噪声打击声），旋律用柔和三角波；「弹」「唱」可分声部开关
- **打印 / PDF**、浏览器自动保存、导出/导入 `.mtab.json`（自动兼容 v1 旧格式）
- **撤销重做**、深色模式、全键盘操作（应用内"帮助"）
- **字体**：仅指定开源字体（思源黑体/宋体、Noto Sans/Serif SC、
  文泉驿微米黑、DejaVu），无任何商业字体依赖
