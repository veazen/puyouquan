# MuseTab —— 新时代的中文吉他谱编辑器

向经典国产吉他谱软件 **Muse** 致敬的现代 Web 复刻：简谱 + 六线谱 + 歌词
三行严格时间对齐，符合中国吉他爱好者的读谱与制谱习惯。

**零安装**：用任何现代浏览器打开 [`index.html`](index.html) 即可使用，
单文件、离线可用、跨平台（Windows / macOS / Linux / 手机平板）。

## 功能（v6 精修版）

- **顶部 Ribbon 工作台**：Office 式分页工具栏——文件/播放常驻主栏，
  **吉他谱 / 简谱 / 歌词 / 小节**四个分页，点谱面自动切页；
  工具栏下方状态条实时显示节拍检查结果
- **共用时值组**：单时值（全/2/4/8/16/附点）与**组合时值**（八分×2、
  前八后十六、前十六后八、十六×4、附点组合、小切分）从三大板块独立出来
  共用，图标为直观的音符图示；组合时值可把当前一个音就地拆分
- **图示化节奏型库**：教材风格（×符头+符干符杠+∧∨扫弦方向）的图示卡片，
  吉他库 24 种（分解/扫弦 × 2/4·4/4 与 3/4·6/8 分类，含交替低音、
  前八后十六分解、十六分流水、放克切音、慢摇滚等），简谱库 17 种；
  每张卡标注拍数
- **多声部**：吉他谱、简谱各最多 5 个声部，歌词最多 5 段，一键增删
- **常用节奏型**：两个板块各内置常用节奏型（分解 53231323、民谣扫弦
  ↓↓↑↑↓↑、柱式、切音律动、前八后十六、附点、大切分等）；Shift+点击可
  跨小节多选，点节奏型即批量套用——吉他板块还会按当前和弦指法自动生成
  分解/扫弦音
- **节拍自动校验**：按拍号检查每小节每声部的时值总和，不符时小节自动
  标红加 ⚠，并在左栏"节拍检查"列出（点击可跳转）
- **弹唱谱结构**（与经典 Muse 一致）：六线谱 = 吉他伴奏，简谱 = 人声
  旋律 + 歌词，声部节奏各自独立、按小节对齐
- **伴奏声部**：点弦位键入品位（0–24）、× 切音/闷音、扫弦箭头（↓↑）、
  琶音波浪线（扫弦/琶音只跨实际弹奏的弦）、符干与同拍符杠（八分/十六分自动连桥）
- **旋律声部**：直接键入唱名 0–7、升降号、高低八度点、附点、
  同拍连体减时线、延音线（–）、连音线（播放时自动延长）
- **和弦**：内置指法库自动补全，和弦图可切换随行显示（每个和弦变化点
  上方画图，如 Muse）/ 曲首集中 / 隐藏
- **反复记号** `|:` `:|`、小节号、左上 `1=X 拍号 速度`、右上作词/作曲/制谱
- **批量填词**：整段歌词一键按音分配，标点自动跟随
- **播放试听**：伴奏用 Karplus-Strong 拨弦合成（扫弦/琶音有扫拂时差、
  切音为噪声打击声），旋律用柔和三角波；「弹」「唱」可分声部开关
- **打印 / PDF**、浏览器自动保存、导出/导入 `.mtab.json`（自动兼容 v1 旧格式）
- **撤销重做**、深色模式、全键盘操作（应用内"帮助"）
- **字体**：仅指定开源字体（思源黑体/宋体、Noto Sans/Serif SC、
  文泉驿微米黑、DejaVu），无任何商业字体依赖

## 背景

"高速下载器"外壳而非 Muse 本体（详见 [ANALYSIS.md](ANALYSIS.md)），
因此本项目基于 Muse 公开的产品理念重新实现并现代化。
