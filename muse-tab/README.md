# MuseTab —— 新时代的中文吉他谱编辑器

向经典国产吉他谱软件 **Muse** 致敬的现代 Web 复刻：简谱 + 六线谱 + 歌词
三行严格时间对齐，符合中国吉他爱好者的读谱与制谱习惯。

**零安装**：用任何现代浏览器打开 [`index.html`](index.html) 即可使用，
单文件、离线可用、跨平台（Windows / macOS / Linux / 手机平板）。

## 功能

- **三行对齐排版**：和弦名、简谱、六线谱、歌词按时间列上下对齐，自动换行
- **像 Muse 一样输入**：点击六线谱弦位直接键入品位数字（0–24），
  简谱按调号自动推导（含高低音点、减时线、延音线、附点）
- **和弦**：内置常用和弦指法库，曲首自动生成和弦图一览
- **批量填词**：整段歌词一键按列分配，标点自动跟随
- **播放试听**：Web Audio 拨弦合成（Karplus-Strong 算法），播放高亮跟随
- **打印 / PDF**：浏览器打印即得纸质谱
- **存取**：浏览器自动保存；导出 / 导入 `.mtab.json` 曲谱文件
- **撤销重做**、深色模式、键盘快捷键（应用内"帮助"）
