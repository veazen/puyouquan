## 1. 总原则

1. **只增不改**：song 字段 0 新增（建出的谱与 P2a 同组合逐字节相同，§14 F2）；`musetab-*` 键 0 新增（`musetab-nw-last` 格式不变——「上次的形态」从它的用途＋变体反推，§8.4）；`musetab-cmd-recent` 只会多存新命令 id（既有键、既有格式）；深链参数名 / `VAR_ORDER` / `LINK_P` 不变；用途 id、`SC` / `VARS` / `GROUPS` / `SCENE_IDS` 常量不变。
2. **零差异**：旧外壳（`?shell=classic`）与 `?next=0` 的 `deskNew()`、`fields()`、`sceneOpt()`、`quickMenuHTML()`、`quickMenuFlowHTML()` 的非 nx 分支、命令表一字不动；手机（`isMobileNew()`）与 ≤820 窄档（`body.flw-m`）走的就是 `deskNew()`，照旧。新界面只在 `p2b()`＝`NW_P2B===1 && NXP()` 为真时出现（`NXP()` 已含非手机 / 非窄档 / `FLOW.nxOn()`）。
3. **回滚一个常量**：`const NW_P2B = 1;`（§13）。改成 0 后新形态的新建面板、快速新建 ▾、命令面板、文件 ▾ 读屏名与 v70.0 逐字节相同（`tv_v701new` F3 / `tv_v701ent` Q3 断言）。
4. **形态只是预设，不是新数据**：每个形态＝已有用途＋已有变体值＋旋律用；选形态走与深链预选同一条 `applyScene ＋ 变体` 路径（`fmApply`，§3.4）；建谱仍是 `planOf → realCreate`，`NWB.build` / `realCreate` / `lastSave` / 埋点一行不改。
5. **新外壳文案预算**：按钮 ≤4 字、菜单项 ≤6 字不带副标题、悬停 ≤12 字、不写位置词。本版新增可见字只有：组名「常用」「谱种」、7 个谱种名（照 `PQ_KIND.PZ`，≤4 字）、形态名（≤4 字，§3.1）、乐器下拉组名「民乐 / 课堂乐器 / 西洋管弦 / 其他 / 键盘」（比 P2a 的「· 简谱 / · 五线谱」短）、命令面板 19 条标题。左栏字数 74 → 59（§12）。新元素一律不加 `title`（悬停字 0 增）。
6. **快捷键不变**：不新增任何按键处理。↑↓ / Home / End 是左栏 listbox 现有处理（只给「谱种行」补一支分发，§7.2）；←→ 是形态 chip 所在 radiogroup 的现有处理；回车在 chip 上＝创建（radio 在表单里的原生语义，§7.3）。左栏 listbox 上**不加** ←→。
7. **单文件后声明覆盖前声明**：本规格新名字基线 grep 为 0 处——`NW_P2B` `PZ_FORMS` `PZ_FORM` `PZ_DEF` `PZ_IC` `IGRP3` `p2b` `fmMatch` `fmHome` `fmApply` `fmPick` `fmSync` `fmHid` `fmRow` `nfCard` `nfCmds` `ccFkeyText`、`st.pick` `st.lastPick`、DOM `nf-pz-*` `nf-fm-*` `nf-forms` `nf-pzg` `nf-g-cy` `nf-g-pz` `nf-qh` `nf-qh-cy` `nf-qh-pz`、`data-act="pz"` `data-act="form"`、测试 `tv_v701new` `tv_v701ent` `tests/lib/nfpick.js` `nfPick` `nfHome` `nfSel` `NF_MAP`。**不要用** `pzMatch`（`PQ_KIND` 已有同名函数，:5844）、`pick`（`data-act="pick"` 是「选择文件」）、`sel`（全局光标）。实现时再 grep 一次。
8. **测试口径**（v69.8 / v69.9 两次 CI 漏跑变红的教训）：每组按 §16 列的 suites 全跑；零差异对拍不改 `deploy.yml`——基线 DOM 快照写成 `tests/fixtures/v701_base.json`（`node tv_v701new.js --write-base` 用 `git show 1122ea3:muse-tab/index.html` 生成并提交，CI 只读文件）；回滚路径用「把被测页里 `const NW_P2B = 1;` 换成 0 的临时副本」（`nfpick.rollbackUrl()`，不需要 git）；几何断言另跑一遍 `--font-ui` 换 DejaVu Sans（同 `tv_v700new` 的 `FONT_INIT`，模拟 CI 字体）；新套件默认进 CORE。
