## 1. 理念

**深海军蓝框架 + 一支电光蓝 + 冷石板中性色。** 科技感靠三样东西：冷色温（表面从暖米换成带一点蓝的石板灰）、明暗反差（深海军框架压住冷白内容区），以及一支明亮的电光蓝，只用在"当前、选中、主行动、链接"这几个位置。它不靠霓虹描边，也不加动画。气质对标 Linear、GitHub 和专业 DAW：精密、安静、像工程软件。

现有的「深色框架」识别保留：主栏、文档页签条、播放坞这三处深色结构原样留着，只是底色从墨绿 `#1f3a34` 换成深空海军蓝 `#0f1a30`。电光蓝放在深海军蓝上最亮，主栏的「个人中心」、播放坞的「▶ 播放」和左轨选中块因此成了全屏最先看到的三个点。品牌渐变由电光蓝过渡到青，只在 Logo 方块和官网主标题渐变字上出现。谱面播放带单独用青色，跟选中的电光蓝分开，一眼能分清"正在播"和"正在改"。

## 3. 色样说明

- **主色：电光蓝** `#2858f5`（色相 226°）。比 Apple 蓝 `#0071e3`（210°）更偏靛、更饱和，所以显得更"电"。白字压在上面是 5.52:1，作为文字放在画布上是 5.06:1。深色主题把强调色提亮到 `#6694ff`，选中块上的字改用深海军 `#06102a`（6.50:1）。主按钮则仍用较深的 `#3a68f2` 配白字（4.73:1），避免主按钮出现深字。
- **框架：深空海军蓝** `#0f1a30`（色相 220°，RGB 均值 30，满足 tv_frame T1 的 <80）。框架上的字有两档：主文字 `#e7edf7` 14.75:1，次级 `#9eb0cc` 7.88:1。框架上的强调字（预设 / 谱库、当前小节号、循环格）用浅冰蓝 `#becdfc`。框架底边有一道 22% 透明度的蓝光发丝线，这是唯一的"光"。
- **表面：冷石板**。画布 `#f3f5f9` < 栏 `#f8fafc` < 卡片纯白 `#ffffff`，谱纸用冷白 `#fcfdff`。深色主题是 `#0b0f17` < `#0f141e` < `#151b27`，带一点蓝，但不偏紫，也不发灰。
- **语义**：危险统一为玫红 `#c8203f` / `#ff6f8e`（349°），与电光蓝相差 123°。成功是绿 `#1d7a40` / `#3ccf7e`（142°）。播放带是青 `#00a3cf`（193°）。以下几项照旧：收藏心 `#e0395a`、收藏红星、独奏 S 琥珀 `#f5b301`、页签保存点、微信绿、窗口红绿灯、少儿课程章色。

## 4. 使用规则

1. **实心电光蓝只放四类位置**：当前 / 选中（左轨当前音轨、分段选中、记谱法点亮、步骤圆点、节拍器开）、主行动（主按钮、个人中心、▶ 播放、开始制谱）、链接与强调字、焦点环。大面积底色一律不用实心蓝，淡底用 `--accent-soft`。
2. **框架只用海军蓝**：主栏、页签条、播放坞、观看页深色浮层、音色加载胶囊、官网 CTA 横幅和课程 toast 共用 `--chrome`。框架上不放实心彩色块，只允许放强调实底按钮。
3. **谱面**：记谱墨色保持近黑 `#141414`，谱纸冷白。选中和光标读 `--sc-pen`（跟随电光蓝）。播放带和播放竖线读 `--play-band`（青），反色纸上的编辑笔用青 `#0098c4`。打印和导出仍是白纸黑字，打印笔色读 `--ed-brand`。
4. **品牌渐变**（蓝 → 天青 → 青）只用在 Logo 方块、官网 `.grad` 主标题渐变字，以及骨架已经接管的 kicker 横杠、步骤序号、头像底、赞助档位边。按钮、背景、描边一律不用渐变（tv_b7a：主按钮不得渐变）。
5. **微光只有两处**：框架 1px 蓝光发丝线，以及 CTA 横幅右上角的径向光。都用 `background-image` 或 inset 发丝线实现，不用外发光 box-shadow（tv_site T11 有扁平化断言）。
6. **框架上的焦点环**改用冰蓝 `--ed-chrome-accent`（电光蓝压在海军蓝上只有 3.14:1），仍是 2px 实色。
7. **深色主题的字色规则**：压在 `--accent` 上用深海军字，压在 `--btn-pri` 上用白字，压在 `--danger` 上用深字，族色实底上读 `--fam-on`。
8. **（审查修订）全站深色框架**：编辑器主栏 / 页签条 / 播放坞与官网顶栏、CTA 横幅、课程 toast 共用 `--chrome`。框架上的「行动」（个人中心、播放、开始制谱）一律 `--btn-pri` 实底白字；框架上的强调字与焦点环一律冰蓝。
9. **（审查修订）谱纸不随主题**：谱纸两主题都是冷白，谱面编辑笔 `#2858f5`、刻版灰 `#475569`/`#5e6d82`、告警 `#c8203f` 在深色主题下也取浅纸值；只有用户主动选「反色纸」才换深纸那套。
