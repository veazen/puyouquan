> 方案阶段产物，仓库零改动。效果全部用 harness 实拍：13 个场景的 2x 截图在 `tc/C/shots/`，拼图 `tc/C/C-grid.png`，与现色板逐张对照 `tc/C/C-compare.png`，色样卡 `tc/C/C-swatches.png`（色样卡为审查前版本，族色以本文 §2.4 为准）。

## 一、理念

**靛黑框架、靛紫强调、冷白纸面。**
这套色调面向「AI 时代的智能制谱」。科技感靠三件事建立：冷色温、深浅框架的明确反差、一支明亮的靛紫强调色。不用霓虹，不用发光，也不加动画。

- 现有的深色框架结构不变（主栏 main-bar、文档页签 doc-tabs、底部播放坞 mixer-dock、观看页浮层），墨绿换成近黑的靛蓝。浅色主题里它像一条稳重的仪表带；深色主题里稍提亮、加饱和，仍能从内容区里辨认出来。
- 表面是带极轻紫偏的冷中性色（--bg #f4f4f9 / 卡片纯白），谱纸用冷白 #fdfdff。记谱墨色仍是近黑 #141414，打印时强制白纸黑字。
- 强调色只出现在「现在在哪 / 现在做什么」的位置：当前工具、选中项、主按钮、链接、谱面编辑笔。
- 品牌渐变「靛紫 → 蓝 → 青」只用在 Logo 方块、官网主标题渐变字和少数品牌时刻，界面其余部分保持单色克制。

## 三、色样说明

- **主色 靛紫 `#5b4cf0`**（深色主题 `#9384ff`）：蓝紫之间、偏蓝的电子靛色，是「智能」的识别色。浅色主题实底压白字 5.62:1。深色主题提亮后当文字用（5.7–6.3:1），实底上配深墨字 `#0e0d1d`（6.39:1）。
- **框架 靛黑 `#161433` / `#1c1a3d`**：近黑但带明确的靛蓝色相（244°）。浅色主题下是一条稳重的仪表带；深色主题下比画布 `#0f0f17` 亮一档、饱和一档，框架结构依然一眼可辨。
- **表面 冷白**：`#f4f4f9 → #f8f8fc → #ffffff` 三级，只带一点紫偏，避免纯灰的冷硬，也和暖米彻底分开。深色是 `#0f0f17 → #14141e → #1b1b28`，同样带极轻靛偏。
- **品牌渐变 靛紫 → 蓝 → 青**：浅色主题 `#5b4cf0 → #3366ee → #0891b2`，尾段压深以保证大字 ≥3:1；深色主题 `#9384ff → #5b9cff → #38cdf0`，更亮更透。
- **语义**：琥珀告警、绿色成功、红色收藏星、红色答错，全部与靛紫在色相上拉开；播放带用极光蓝 `#1f8be6`，与紫色选中区分。

## 四、使用规则

1. **实心强调**（`--accent` 实底）只用于：当前工具和选中项（左轨当前音轨、时值/品位当前钮、分段当前项、记谱法点亮、步骤圆点）、框架上的主行动（播放、个人中心）、会员角标。每屏实心强调块控制在 3–5 个以内。
2. **主按钮**一律 `--btn-pri` 实底白字，不用渐变（tv_b7a 断言）。深色主题仍是 `#5b4cf0` 白字，和提亮的 `--accent` 选中块分工明确：前者是动作，后者是状态。
3. **框架**（主栏、页签条、播放坞、观看页浮层、**官网顶部导航**、官网 CTA）只用 `--chrome*` 族。框架上的强调字读 `--ed-chrome-accent` / `--site-nav-on`（淡紫），不直接用 `--accent`；框架内焦点环统一 `#8576f8`。框架发丝线 `--glow` 只是 1px 内描线，不做外发光。
   - **`--paper` 只给谱纸**：界面控件（卡片、下拉、键帽、芯片）一律读 `--panel` / `--toolbar`。深色主题下 `--paper` 恒浅，拿它当控件底就是白卡配浅字（审查 R1 修掉了 20 处）。
4. **谱面**：记谱墨色恒为近黑。选中、光标读 `--sc-pen`（恒为浅色靛紫，因为谱纸两主题都是浅色）。播放带、播放竖线读 `--play-band`（极光蓝）。刻版灰恒为纸面值。打印和导出一律白纸黑字（五种主题状态 × print 已实测 `--paper:#fff`、`--ink:#000`）。
5. **品牌渐变**只用于：Logo 方块、新建卡顶条、启动遮罩 Logo、官网主标题的 `.grad` 渐变字、kicker 短横杠、步骤序号、头像底、赞助档位「最受欢迎」边框、统计数字与价格渐变字。不用于按钮、整块面、正文。
6. **不做**：霓虹描边、发光阴影、动画流光、紫青大面积铺底。微光只允许出现在官网 CTA 右上角那层极淡的青色径向渐变。
