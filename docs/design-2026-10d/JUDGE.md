# 全站科技感色调：三套方案横评与推荐

> 本文是方案阶段的横评。仓库没有改动，`git status` 是干净的，也没有 commit。所有效果都是 harness 对现版 v66.4 实拍的截图（2x，浅色和深色），不是示意图。
> 评审范围：每套 13 个场景，逐张看过；另看了官网 17 页 × 明暗的扩展实拍、编辑器隐藏态补拍、三份 palette.md 和审查结论。三套的对比度清单复跑结果：A 120/120、B 173/173、C 118/118，全部 PASS。

## 结论

**推荐 B「石墨青」。** 框架用石墨黑，强调用信号青，表面用冷灰。观感接近录音台或示波器那种仪器面板，主张的是"专业、精密"，不靠"AI 炫彩"。

- **想要更鲜明的"AI 时代"气质**：选 C「极光靛紫」。落地前要先修两处，见第 5 节。
- **不建议 A「深空蓝」作首选**。它最常见，看起来最稳，但和负责人推翻过、否决过的三版配色同属一个蓝色族，被再次否决的概率最高。

三套都做到了以下几点：

- 保留"深色框架"这个结构识别。
- 版式、尺寸、圆角、字体、字重、图标一律不动。
- 谱纸在两个主题下都是冷白，记谱墨色近黑，打印仍然白纸黑字。
- 谱面刻版灰在深色主题下改为固定取纸面值，修掉了现色板 2.5:1 的老问题。
- 官网顶栏都并入了深色框架。这是审查时为避开 Apple v4 首屏观感而统一加上的改动。

## 2. 打分（1–10 分；"落地成本与风险"一项分越高表示越省、越稳）

| 维度（权重） | A 深空蓝 | B 石墨青 | C 极光靛紫 |
|---|---|---|---|
| 科技感（25%） | 7 | 8 | **8.5** |
| 品牌契合（20%） | 6.5 | **8.5** | 7 |
| 长时间制谱舒适度（15%） | 8 | **8.5** | 7.5 |
| 谱面可读性（15%） | **8.5** | 8 | **8.5** |
| 辨识度（15%） | 5.5 | **8.5** | 7 |
| 落地成本与风险（10%） | 6.5 | 7 | 7 |
| **加权合计** | **7.0** | **8.2** | **7.7** |

### 每一分的理由

**A 深空蓝**

- **科技感 7**：海军蓝配电光蓝是公认的科技配色。但文字和表面几乎就是 Tailwind 的 slate/blue 默认值（`#0f172a` / `#475569` / `#1d4ed8`），是"通用 SaaS 的科技"，不够"现在"。
- **品牌契合 6.5**：蓝色传达专业、可信，教育感也强。但它几乎是 v40.6 之前那版"保蓝"配色（旧蓝 `#3a5ce0` 228°，靛墨框架 `#262b40`）的高饱和版，而那版正是负责人亲自推翻的，品牌叙事上等于走回头路。
- **舒适度 8**：冷石板表面加海军蓝框架很安静。电光蓝饱和度高达 91%，但用量受控。
- **谱面可读性 8.5**：谱纸冷白、墨色近黑。深色主题下谱面也取纸面值：刻版灰 7.45、小节号 5.18。青色播放带和蓝色光标能一眼分开。
- **辨识度 5.5**：强调色 226° 和已否决的 Tesla v3 蓝（`#3e6ae1`，224°）色相几乎相同，和 Apple v4 也是同一家族。国际主流制谱软件也多用蓝色系。
- **落地 6.5**：CSS 层很成熟，但有几处欠账：
  - 深色主题"白卡浅字"没修。新建向导、帮助卡、键帽等约 20 处拿 `--paper` 当控件底，对比度 1.1:1。B 和 C 都修了。
  - 输入框占位符的修复也没做。
  - 危险色从琥珀改成玫红，属于语义变更。
  - 被再次否决的风险最高。

**B 石墨青**

- **科技感 8**：石墨机身配信号青读数，是示波器、录音台那种"仪器科技"。深色主题是三套里最有科技味的。扣分在浅色主题：品牌渐变在审查时被收成同色相（为了让白字和标题过对比度），Logo 和主标题显得偏平。
- **品牌契合 8.5**：负责人 2026-08-31 定的对外话术是"专业曲谱平台（出版级·科教级）"，并明确"勿再用智能曲谱平台"。B 讲的正是精密工具，不讲智能噱头。音频硬件的视觉语汇和音乐天然相通，老师、考编、艺考用户都不会觉得花哨。
- **舒适度 8.5**：框架是中性石墨，表面是低饱和冷灰，强调色明度低，一屏只有一个亮色，最适合几个小时连续制谱。
- **谱面可读性 8**：谱面取纸面值，刻版灰 6.68，编辑笔对纸约 5:1。扣分点是播放带和编辑笔同色，"正在播"和"正在改"的区分不如 A、C。不过这和现色板的行为一致，不算回归。
- **辨识度 8.5**：三套里唯一没有历史包袱的色相：不是蓝，不是朱砂，也不是紫。和 Apple v4、Tesla v3、v40.6 前的旧蓝、主流制谱软件都拉开了距离。
- **落地 7**：验证最完整：
  - 173 对对比度全过。
  - 五种主题状态加打印逐项核对。
  - 自写文字扫描 0 处不达标（基线浅色 55 处、深色 97 处）。
  - 顺手修掉的现存 bug 最多。
  - 代价：危险色统一为信号橙，要确认它和 `--warn` 琥珀并排时分得开（见 §4）；改动的选择器面也最大。

**C 极光靛紫**

- **科技感 8.5**：靛紫加"极光"渐变是 2024–26 年 AI 产品的标准语汇，最"现在"，也最一眼科技。
- **品牌契合 7**：直接呼应北极星"AI 时代的智能制谱"。但负责人已经把对外话术从"智能"改成"专业"。而且靛黑框架加蓝紫，正是 v40.6 前品牌的色族（PROJECT.md 记为"蓝紫"和"靛墨"），负责人当时推翻过。
- **舒适度 7.5**：表面带紫偏，强调色饱和度高（85%）。深色主题下选中块是淡紫实底，偏软偏亮，长时间看比 B 累。
- **谱面可读性 8.5**：谱面取纸面值，刻版灰 6.46。极光蓝播放带和紫色编辑笔分开。
- **辨识度 7**：跳出了蓝色，在制谱品类里可以区分开。但靛紫加渐变已经是 AI 产品的大众脸，主色 `#5b4cf0` 和 Stripe 的 `#635bff` 几乎相同。
- **落地 7**：编辑器的语义色（危险琥珀、成功绿）几乎不动，测试改动面最小。但有两处必须修正：
  - 官网 `--danger` 改成琥珀 `#b45309`（26°）后，和 `--warn` 琥珀 `#b7791f`（36°）只差 10°。管理台的"驳回 `.k-no`"和"待审 `.k-wait`"同屏出现时分不开。
  - 功能族仍然是暖色琥珀，封面洗成沙色，带"暖米"的影子，需要拍板。

## 3. 推荐理由：为什么是 B，而不是科技感分最高的 C

1. **负责人已经给出的三个信号，B 全都踩对了。**
   - **v40.6 的拍板**：负责人推翻了"保蓝"决策，改用素材配色，旧的蓝紫加靛墨框架被放弃。A 是那版的饱和版，C 是同族的偏紫版。
   - **2026-10 的两次否决**：Tesla v3 和 Apple v4 都以蓝色为强调色。A 的色相和 Tesla v3 只差 2°。
   - **2026-08-31 的定位**："专业曲谱平台"，不说"智能"。颜色是对外的第一句话，B 说的是"专业仪器"，C 说的是"AI 智能"。
2. **科技感差距小，B 有空间补齐。** B 和 C 在科技感上只差 0.5 分，而且 B 的差距集中在浅色主题渐变偏平这一点。落地时可以用标题渐变字的专用令牌 `--grad-text` 把光泽补回来（§4 第 2 条）。C 在品牌契合和辨识度上的差距，则来自色相本身，改不掉。
3. **最适合本产品的使用方式。** 用户是老师、考编生、艺考生，连续几个小时录谱、改谱。B 中性石墨加一个低明度亮色，视觉疲劳最低，谱面始终是主角。
4. **工程上最扎实。** B 修掉的现存问题最多：深色白卡浅字、深色谱库卡片曲名近黑、框架上读错令牌的文字、免费价签、占位符、渐变上的白字等。验证口径也最全，落地风险最可控。
5. **更换感足够明显，又不刺激。** 朱砂、墨绿、暖米三样旧识别全部换掉。框架从墨绿换成中性石墨，强调色从暖红换成冷青，是一眼可见的换代。但这次版式完全不动，不会重蹈 v4"整体改版"的覆辙。

## 5. 备选说明

### 改选 C「极光靛紫」：比 B 多出的落地差异

1. **官网 `--danger` 保持红**（`#c0392b`），不要改成琥珀，否则和 `--warn` 撞色。编辑器维持琥珀不变。
2. **功能族要拍板**：保留琥珀 `#965a00`（分类用暖色对位，封面会洗出沙色），还是改成品红类（参照 B 的 `#a3367f`；贴近收藏心的问题需要实拍确认）。候选色样在 `tc/C/review/fam-f-candidates.png`。
3. **可选**：品牌渐变中段 `#3366ee` 是纯系统蓝，主标题有一半会读成"系统蓝"。可以往靛蓝方向靠一点，各停点仍须 ≥3:1。
4. **深色主题两种紫并存**：选中块淡紫 `#9384ff`，主按钮 `#5b4cf0`。要统一的话，约 20 处"accent 作文字"要改读 `--accent-ink`。
5. **测试**：在 B 的三条之外，`tv_mviews` T5 若在深色主题下断言 `#sb-go` 白字，需改成深墨字。

### 改选 A「深空蓝」：需要补的项

1. 移植 B 或 C 的深色"白卡浅字"修复（`--ed-raise`，约 20 个控件选择器）和 `::placeholder` 修复。
2. 危险色改玫红是语义变更，要和负责人确认。
3. 汇报时必须正面回应"又是蓝 / 回到旧蓝"的疑问。不建议作为首推。

### 6.1 编辑器令牌与写死热点（`muse-tab/index.html`）

1. **令牌块（L33–80）**
