## 理念

参照物是专业录音设备的面板：机身是石墨黑，读数和指示灯是一束信号青，工作台是冷灰。编辑器原有的“深色框架”结构保留下来（主栏、文档页签条、底部播放坞），只是把墨绿换成中性略冷的石墨；官网顶部导航也并入这块石墨框架，全站一个顶栏。界面里只有一个亮色，就是青：当前工具、选中、主按钮、链接、播放和光标都用它，别的地方一律不用。科技感靠三样东西：色温冷、明暗对比干脆、只有这一个亮色。不用霓虹，不加动画，也不加发光阴影。框架底边那条 1px 青色发丝线，是整个方案里唯一的“电子味”装饰。谱纸始终是近白的纸，记谱墨色保持近黑。打印和导出照旧是白纸黑字。

## 使用规则

1. **实底强调色只用在“当前和主行动”上**：当前工具（左轨当前音轨、编辑条点亮键、当前时值）、主按钮、播放钮、个人中心入口、步骤圆点。一屏之内实心青块不超过 3 到 4 个，其余状态用 `--accent-soft` 淡底加 `--accent-ink` 字。
2. **文字永远读 `--accent-ink`，不读 `--accent`**：链接、淡底上的强调字、导航当前项都用它（本方案已把官网 `#menu a.on`、编辑器 `.pcx-side button.on` 改读它）。浅色主题的 `--accent` 当文字只在白卡片上勉强够线（5.17），所以不要放在画布上当正文用。
3. **深色主题的两档青**：信号青 `--accent` 实底压深字 `--ed-on-accent`/`--site-on-accent`；主按钮 `--btn-pri` 是深青，压白字。两者各管各的，不要混用。
4. **框架（石墨）是结构，不是装饰**：只用于编辑器主栏、页签条、播放坞、观看页深色浮层，以及官网顶部导航、CTA 横幅和 toast。框架上的字读 `--chrome-text` / `--chrome-muted`，框架上的强调字读 `--ed-chrome-accent`（信号青 `#67e3f0`），不要读浅色界面的 `--muted` / `--accent-ink`，否则只有约 2:1。
5. **谱面强调跟着纸走，不跟着主题走**：谱纸恒为近白，所以选中、光标、播放带、刻版灰（作曲署名、小节号）、谱面告警在两个主题下都取纸面值（深青 `#08788a`、灰 `#525c67`、橙 `#c2410c`）。反色谱纸（深纸）单独用信号青 `--ed-invert-pen`。打印分支照旧强制白纸黑字，刻版灰走 `--ed-print-*`。
6. **品牌渐变只用于品牌标识**：Logo 方块、新建卡顶条、官网 kicker 横杠、步骤序号、头像底、赞助档位边，以及官网大标题的渐变字（读 `--grad-text`）。按钮、正文、图表都不用渐变。tv_b7a 规定主按钮必须是实底。
7. **语义色不跟品牌**：告警一律信号橙，成功一律绿；收藏心 `#e0395a`、收藏星红、独奏 S 琥珀、微信绿、窗口红绿灯、少儿课程章色 `--kh*` 都按骨架登记的语义清单保留。

## 本方案顺手修掉的现存问题（都只改颜色）

1. **深色主题下的“浅底浅字”**：编辑器有 20 处 UI 把谱纸色 `--paper` 当白底用（新建向导三张类型卡、乐器/形态下拉、导入卡、指板/键盘分段钮、变调浮层芯片等），而 `--paper` 在深色主题下仍是浅色，结果字和底都是浅的（1.1:1）。新增 `--ed-raise`：浅色主题＝`--paper`，像素不变；深色主题＝`#20262d`。
2. **深色谱库卡片的曲名和封面数字看不清**：它们读的是 `--ink`（谱面墨色，深色下仍近黑），压在深色卡上只有 1.25:1。改读 `--text`。
3. **深色谱纸上的刻版灰只有 2.5:1**：作曲署名、小节号原先跟随深色主题的浅灰。现在谱面隔离层取纸面值。这正是 v66.0 注释里写的“二期换肤时谱面编辑笔/刻版灰另行定值、不随主题漂移”。
4. **框架上的文字读错令牌**：播放坞声像值“自动”、手机播放坞标签、手机「智能」钮原来读浅色界面的 `--muted` / `--accent-ink`，压在深色框架上只有约 2:1。改读框架令牌。
5. **官网导航当前项和个人中心侧栏当前项**：强调字压淡底，原 4.33 / 4.05，改读 `--accent-ink` 后约 6.7。
6. **官网旧版课程按钮写死 `#fff`**（`.kc-done .kc-tick`、`.kc-quizbtn.pass`、`.kq-next`、`.kc-ckbtn.on`、`.kc-testbtn`）：深色主题下族色和章色都是提亮色，白字只有 2 到 3.7:1。改读 `--fam-on`，浅色主题下仍是 `#fff`。
7. **免费价签对比度不达标**：原 3.36:1，现 5.43 / 9.51。
8. **输入框占位字**（审查追加）：全站没有 `::placeholder` 样式，走浏览器默认 `#757575`，深色主题压 `--panel` 只有 3.60（现色板 3.20）。两边都补 `::placeholder{color:var(--faint)}`：5.95 / 5.65。
9. **品牌渐变上的白字和渐变标题**（审查追加）：头像字、步骤序号压在渐变上，原尾段白字 3.05；浅色渐变标题「专业曲谱平台」尾段压画布 2.72，大字也不到 3:1（现色板同样不达标）。改为同色相深浅光泽后全部达标。
