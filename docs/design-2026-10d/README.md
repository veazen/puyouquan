# 全站科技感色调方案（2026-10-10）

> **状态：已拍板采用 C「极光靛紫」（2026-10-10 负责人「用C方案」），v66.5 上线为全站默认。** 细项：官网告警色保持红、收藏星/心保持红、深色顶栏与功能谱琥珀族按效果图；未做预览开关；小程序未改。下文为方案阶段原文（当时推荐 B），保留备查。
> 负责人原话：「更改全站色调，要一个现在的有科技感的色调。给我方案效果。」

## 做法

- **只换颜色。** 版式、尺寸、间距、圆角、字体、字重、图标、文案都不动，编辑器和官网保持 v66.4 现状（Apple 风格撤回后的版本）。保留「深色框架」这一结构识别：编辑器主栏、文档页签条、底部播放条，现在是墨绿，三套方案各自换成新色。
- **效果图是实拍。** 每套色调做成一层只改颜色的样式，叠到现行编辑器和官网的真实页面上截图（`tools/harness.js`），不是另画的示意稿。每套 13 个场景：编辑器浅色 / 深色、启动台、播放中、新建弹窗、手机看谱、钢琴谱深色，以及官网首页浅色 / 深色、考编页、制谱页、学习页、手机首页。
- **验证。**
  - 截图探针扫描三套的 13 个场景，旧色（朱砂 / 墨绿 / 暖米）残留均为 0。唯一例外是官网「制谱」页演示窗口左上角的红绿灯小圆点，属于有意保留。
  - 对比度全部达标：A 120/120、B 173/173、C 118/118。标准是正文和三级文字 ≥4.5:1，主按钮白字 ≥4.5:1，焦点环 ≥3:1。
  - 谱纸在两套主题下都是冷白，记谱墨色接近纯黑；打印和导出仍是白纸黑字。
- **色调骨架。** 先把编辑器和官网所有写死的颜色盘点出来，改成可整体换值的令牌（`skel/`）。令牌取现有颜色时，13 个场景与现状逐像素一致（差为 0），说明以后换色只需改一组值。
- 流程：盘点 → 三位设计师各出一套 → 三位审查员逐套挑错并直接修正 → 评审横评。横评全文见 `JUDGE.md`。

## 三套速览

| | A 深空蓝 | **B 石墨青（推荐）** | C 极光靛紫 |
|---|---|---|---|

| 表面 | 冷石板 `#f3f5f9` + 白卡 | 冷灰 `#eff2f4` + 白卡 | 微紫冷白 `#f4f4f9` + 白卡 |

## 推荐 B「石墨青」的理由

1. **没有历史包袱。** 蓝色系已经三次被推翻：v40.6 推翻了 v40.0「保蓝」的配色（旧蓝 `#3a5ce0`），Tesla v3 用蓝，Apple v4 也用蓝。A 的主色和旧蓝只差 2°；C 与旧的蓝紫、靛墨同族，主色也接近 Stripe 的 `#635bff`。青色是唯一没用过的色相。
2. **贴合对外定位。** 2026-08-31 定的对外话术是「专业曲谱平台」，不再用「智能曲谱平台」。B 传达的是专业仪器的精密感，不靠 AI 炫彩。
3. **长时间录谱最舒适。** 老师和考生常常连续几小时录谱。B 是中性石墨框架加低饱和冷灰，一屏只有一个亮色，谱面始终是主角。
4. **验证最完整。** B 的对比度检查覆盖最多（173 项），还顺手修掉了几处现有问题：深色主题下白底卡片配浅字、谱库卡曲名近黑、占位符看不清。

如果想要更鲜明的「AI 时代」气质，可以选 C，落地前要先修官网危险色和待审色撞色的问题。A 不建议作首选。

## 需要负责人拍板

1. **选哪一套**：推荐 B，备选 C。
2. **是否先上预览开关**：先把新色调做成线上预览（网址加 `?tone=graphite`，只在当前浏览器会话里生效，不新增本地存储键），真机看 1–2 天再切默认。建议要，v4 就是看效果图拍板、上线后才否的。
3. **官网顶栏是否也改成深色框架**：三套都做了，这样全站只有一种顶栏；也可以保留浅色顶栏。
4. **告警色**：B 是全站统一为信号橙；稳妥做法是语义色不动（编辑器琥珀、官网红）。
5. **小程序是否同步换色**：需要重新提审。

另有两项细节，默认保持现状：谱类配色里「功能谱」一族在 B 中改为品红；收藏红星保留现在的红色。
