# 评委：owner

## 评审结论：以方向 A 为底，嫁接 B 的音轨层级与 C 的若干细节

### 0. 先说结论
- **推荐方向 A「工作流模式」作为外壳底稿**，加权 7.8 分，B 6.9 分，C 6.2 分。
- 但不原样采用。要做三件事：
  1. 把五段收成四段：书写 › 排版 › 播放 › 输出。
  2. 左栏音轨区改用方向 B 的「记谱法层」语义。
  3. 记号按钮用方案 1（SMuFL 字形），电脑端默认带字。
- 选 A 的理由：
  - 它把「出版级」做成了界面结构本身：排版模式有分页、版心、版面检查；输出模式以打印预览为主视图，平铺分谱、导出和发布。
  - 它在三套里离现状外壳最近：深色主栏 + 浅色工具带 + 左栏 + 右栏。被当成「又一次换风格」再次否决的风险最低。
  - 实测空间收益最大且稳定：顶部 162→84px；1280×800 谱面可见高 586→676；左栏常开时谱纸 870/870。

### 2. 为什么不选 B 和 C 做底稿

**方向 B**
- 它的左栏树是最好的：轨下面列出简谱 / 五线谱 / 简谱行 / 和弦 / 歌词各行；眼睛开关是可叠加的层，两个都亮就是 voxDual；「五线谱联排」挂在组级并写明「全部吉他轨」。
- 但功能区展开后外壳仍有 144px，已有谱的谱面可见高只从 573 增加到 600。功能区很密，「记号」页有 49–54 个 28px 无字格。
- 实拍有缺陷：单行模式的音级键顺序是「1 5 2 6 3 7 4 0」（dirB/shots/real-06-pacc-line_1280-light.png）。
- 当前页签被截成两个字（real-10）。
- 整体观感是办公软件，正面撞上负责人「不够精致」的批评。

**方向 C**
- 观感最轻。但三个问题都是「会被再次否决」级别的：
  1. 记谱法用排他的「简｜五｜六」分段，表达不了 voxDual。这正是 v38.9 回退时记下的「三选一切换与联排渲染架构冲突」（PROJECT.md 第 457 行）。
  2. 一行顶栏 + 谱面上方工具条 + 右侧检查器，与 v38.9 回退稿、v66.2 skin-next、design-2026-10 的外壳目标形态同构。
  3. 点选后浮条自动弹出，实拍里压住了歌词、合唱声部行和和弦图（compare-pacc-1280-light.png、05-choir-wide、03-gtr-tab-ctx）。

### 3. 推荐的合成方案

**顶栏第 1 行（44px，深色）**
- 从左到右：品牌 · 文件 ▾ · 窗口页签 · 「书写 › 排版 › 播放 › 输出」四段 · 保存状态与保存 · 发布（唯一主色按钮）· 账号 ▾。
- 「设置」不再单列为一段。它的内容并入「文件 ▾ › 曲谱信息… / 换谱类…」和音轨区的 ⚙ / ⋯。

**顶栏第 2 行（40px）**
- 按模式换内容，单行显示，放不下的收进「更多」。
- 「书写」模式的第 2 行就是现在的 editbar，老用户录入路径不变。

**左栏（248px）**
- 上半是音轨：
  - 用方向 B 的层级语义：旋律轨下是「简谱 / 五线谱」两层，可叠加，两个都亮就是对照；TAB 轨的「五线谱联排」放组级并标明整曲范围；「由此生成六线谱轨…」做成动作行。
  - 用方向 C 的谱号徽标（𝄞 / 𝄢）区分右手、左手。
  - 歌词子行保留 A 的做法。
- 下半是记号面板：方案 1 字形，默认带字，分组折叠，支持拼音搜索和最近使用，标题写「作用于 xx」。

**右栏**
- 分「属性｜智能」两页；「智能」页顶部是「下一步」卡，接住谱型条的起步三步。
- ≥1440 宽时停靠，1280–1439 宽时收成 40px 竖条，让位规则用方向 C 的 paperClear 公式并写成几何断言。

**页签**
- 并入第 1 行。最小宽 120，当前页签 ≥148 且不截断。1280 宽目标是至少露 5 个。
- 溢出列表可搜索，加上方向 C 的「关闭已存入的窗口」。
- 状态只标「未入库」空心圈，撤掉写死的橙、绿色。

**命令面板（Ctrl+/）**
- 吸收方向 C 的两点：每条结果写明「在界面哪里」；能搜旧名（预设 / 打印… / 智能）。
- Ctrl+K 保持和弦快速输入，不改。

**浮条**
- 不自动弹出。保留右键浮条，只吸收方向 C 的「常用 3 个按本机习惯排序」（habitTop）。

- 方案 2 的字母类记号（f<、tr〜）看起来像画出来的，不像刻出来的（见 icons/SPEC.md §4.3）。

**落地必须同时打的补丁**
1. 品位数字族（击弦、勾弦、滑弦、推弦等）：S 提到约 5.3；仍不够大时，只有这一族允许「sans 13px 数字 + SMuFL 记号」混排。
2. 16px 场景（手机、菜单）用 sign16 母版，禁止把 20 母版用 CSS 缩小。
3. 字母类记号必须换成谱面同一字面：力度用 Bravura dynamic* 字形，技法字用 Georgia 斜体轮廓（L9186 / L10765 那套字面）。方向 A 原型里的 Liberation Serif 占位不能上线。

**电脑端默认显示「带字」**
- 默认用 52×52 带字格，标签 11px，可以切到 36×36「只看字形」，偏好存新本机键 `musetab-signdensity`；手机固定带字。
- 附着类记号（跳音、断音、保持音、重音、顿强、延长、换气）吸收方向 B 的「三语境」画法：简谱轨画在灰色唱名 5 上，五线谱轨画在灰色符头上，六线谱轨画在灰色品位 3 上。语境元素墨色 50%，对比度 ≥3:1。
- 方案 2 只作为备用：如果老师试用后觉得 1x 下太小，再整体切换，两套键名一一对应。

## 必须修改
- 模式从五段收成四段：书写 › 排版 › 播放 › 输出。「设置」的内容并入「文件 ▾ › 曲谱信息… / 换谱类…」和音轨区 ⚙ / ⋯；默认停在书写，按 Esc 回书写；不默认绑定 Alt+数字（Linux 上和浏览器切标签冲突），快捷键在四个浏览器实测后再定。
