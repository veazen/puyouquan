A 和 B 几乎打平，我选 B 作底，原因有二：
1. **B 的短板是参数级的，能用数字修好。** 包括高度、切选项卡的额外点击、五线谱键位。
2. **A 的短板是结构级的。** 五个模式会把工具藏起来，「设置 / 书写」不是老师的说法，模式条还挤占了页签的位置。C 的多窗口和「记谱法切换藏起来」也是结构问题。

负责人点名的三件事，B 都是最直接的解法：
- **左栏**：只放音轨树，对象和工具分开。
- **顶栏**：「开始 / 记号 / 文字与歌词 | 排版 | 播放 | 输出」本身就是写 → 排 → 出的出版流程，而且老师天天用 WPS，零学习成本。
- **多窗口**：并进标题栏，6 个窗口全部露出。

## 记号按钮方案
我选方案 1（SMuFL/Bravura 字形），再打四个补丁：

1. **默认带中文名**：老师默认看到「字形 + 中文名」的 52×52 格子，也就是 C 记号抽屉和 icons/SPEC 的带字档。「只看字形 36×36」和功能区里 28×28 无字的格子，留作熟手的选项。
2. **语境底音**：嫁接 B 的三语境画法，记号画在灰色底音上。简谱轨画在「5」上，五线谱轨画在符头上，六线谱轨画在品位「3」上。
3. **品位数字类**：击弦、勾弦、滑弦、推弦这一族改用「sans 13px 品位数字 + SMuFL 记号」混排（SPEC §6.3），解决 1x 下数字只有约 5px 高的问题。
4. **16px 场景**：手机和菜单一律用 sign16 母版，不缩放 20px 母版。

功能动作仍用 pqIcon 同格式的线性图标。两套图标一图一义、互不混用。

理由：我平时认的是谱面符号。按钮上的 Ped.、mf、延长号如果和印出来的谱是同一个字形，我不需要再学一套图标。

## 必须修改

- 五线谱轨的音高键必须用 C D E F G A B，并在音名旁标出本调级数（照搬 C 的 C₁ D₂ E₃）。A 和 B 原型在左手伴奏轨上都显示 1–7，这是对现状 v67.7 的倒退（dirA-t1-3-lh.png、dirB-t1-4-home-lh.png）。
- 「开始」选项卡加一个「常用记号」组：放最近用过的 6 个记号，读 musetab-habits；首次使用时默认放延长号、重音、连音线、渐强、mf、跳音。这样加完记号就能直接改音，不用来回切选项卡，任务①从 7 次点击降到 5 次。
- 尤克里里必须说清楚：现在乐器和弦线数是整谱级的（index.html L3553 instOf()、L3554 strN()、L14913 加轨菜单名随 song.inst 变），一份谱里不能同时有 6 线和 4 线。加轨菜单里要出现「尤克里里轨」：在吉他谱里点它时，说明原因，并提供「以本谱旋律另建一份尤克里里弹唱谱（新窗口）」，复用新建面板 NWP 或换谱类里的「另建一份」。「同谱混排」需要新增可选字段，属于待拍板。不准再出现点了没反应的「乐器与音色…」。
- 切换音轨时，谱面自动滚动到该轨当前小节，并留出至少 40px 余量。现在 B 切到左手后，左手谱表只露在 y≈690–725 的半截。
- 弹层纪律：选完就收起，换轨时关闭所有残留弹层。现在 C 的力度菜单、A 的加轨菜单都会残留，盖住谱面或 ⋯ 按钮。页签悬停卡至少延迟 600ms 才出现，而且不准盖住功能区（dirB-t1-0-pacc.png）。
- 同一棵音轨树里不准出现两种同形不同义的「眼睛」：记谱法行的眼睛表示显示或隐藏这种记谱法，轨行的眼睛表示「隐藏此轨」。轨级的「隐藏此轨」在拍板前先不显示，或者换成「不打印」图标。
- 页签规则：1366 宽、6 个窗口时必须全部露出，每个页签至少读得出 8 个汉字（B 现在 147px，已达标）。当前页签永远在可见范围内。关闭一个已经入库的窗口时，提示里不要再说「并存入我的曲谱」。
- 记号格对老师默认显示中文名。功能区展开态下，低频组（装饰音、跳转、小节线·反复）给出文字，或者超级提示第一行写老师的叫法，例如「跳音（断奏点）」「波音」。28×28 无字的格子只用在单行模式和熟手模式。
- 落地红线：只新增本机键 musetab-ribbon、musetab-qat、musetab-rdock，读写都包 try/catch；song 字段新增 0 个。旧 DOM 保留为隐藏的委托宿主。先用 ?shell=ribbon 灰度，跑 check-syntax、tv_matrix.js，以及 26 个引用外壳的套件，迁移它们的几何断言后再切默认。简谱、TAB、五线谱的渲染路径不准动。
