结论（四位评委一致）：**方案 1**。合稿落地的补丁与一处修正：
- **修正**：核实谱面后，文字类记号（力度、D.C. / D.S. / Fine、rit.、P.M.、标注）在谱面上是 `font-family="Georgia,serif"` 斜体 700 的文字（`index.html` L9184–9186、L11882、L11899、L10765），不是 Bravura `dynamic*`。owner / engraver「用 Bravura dynamic*」的初衷是「按钮＝谱面同一个字形」；照字面执行反而会让按钮和谱面不同形。所以合稿用**与谱面同一字体声明的活文字**（`icons/text/*.svg`、`icons/pq-textsig.js`），Liberation Serif 占位不上线；Ped. / ✱ / 8va / 3 连音等谱面本来用 SMuFL 的仍用 Bravura。若将来谱面力度改用 Bravura（渲染改动，需 tv_matrix 全量回归），按钮跟着换——列为拍板 5。
- 品位数字族 em 1.55 → 1.78、族缩放下限 5.3，1x 数字高约 6.9px（≥6.5）；击勾弦只留两个数字。
- 附着记号三语境（`--jp / --tab / --bare` 变体，`work/gen_signs.py` 生成）：简谱灰 5（直立 DejaVu Serif Bold，即 `--font-num`）、五线谱灰符头、六线谱灰品位 3，语境墨 50%；连音线画成「5⌒5」/ 带符干的两个音符 / 「3⌒3」；只看字形档里跳音、保持音、楔形不画语境并放大 1.4 倍（上限）。
- 16 母版供手机与菜单（`icons/sign16/`），不缩放 20 母版。
