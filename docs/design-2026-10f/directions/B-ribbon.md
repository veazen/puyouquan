## 0 结论

**一句话**：顶栏改成 Office / WPS / Sibelius 那样的选项卡功能区。左栏只管「对谁做」，功能区管「做什么」。

- **顶栏**分三层：
  - 一行深色标题栏，放快速访问、窗口页签和「发布」。
  - 一行选项卡。
  - 下面是分组功能区。
- **选项卡顺序**按出版级制谱的「写 → 排 → 出」排：文件｜开始 记号 文字与歌词｜排版｜播放｜输出｜智能 视图。新谱另有一个上下文选项卡「新谱起步」。

## 1 理念

1. **用户本来就熟悉这套用法。**
   - 主攻用户是考编教师、师范生、艺考生、合唱指挥，每天都在用 WPS 和 Office。
   - 出版级制谱软件里，Sibelius 从 2012 年起也是功能区。
   - 「选项卡 + 分组 + 大小按钮 + 组名在下」这套结构，老师一眼就知道去哪找；「专业」也直接体现在界面结构上。
2. **对象和工具分开。**
   - 现在左轨把音轨（对象）和「歌词 / 小节 / 段落」（工具页）做成同形同色的方块，会出现两个按钮同时高亮。
   - 方向 B 的左栏只放对象（轨、行），功能区只放工具。一列只放一类东西。
3. **按工作流排序。**
   - 选项卡从左到右是：写（开始 · 记号 · 文字与歌词）→ 排（排版）→ 出（输出）。
   - 这对应「专业曲谱平台：出版级 · 科教级制谱」的定位。
4. **把护城河做进工具里。**
   - **三记谱法同源**：每条轨下面直接列出「简谱 / 五线谱 / 六线谱」行，眼睛开关就是记谱法切换，而且是真实刻版。
   - **记号格带语境**：同一个「跳音」，在简谱轨上画在灰色唱名 5 上，在五线谱轨上画在灰色符头上，在六线谱轨上画在灰色品位 3 上。
   - **出版级刻版**：记号按钮用谱面同源的 Bravura 字形。
   - **织体与配谱**：在「智能」选项卡和「新谱起步」里。
   - **八场景入口**：「文件 › 新建」复用新建面板 NWP。
5. **演进，不换肤。**
   - 颜色令牌全部用原值。
   - 现有 101 个 pqIcon 不动。
   - 不用渐变洗色，不做左边框卡片，不用 emoji。

## 3 顶栏主菜单

### 3.1 标题栏（深色，36px）

从左到右依次是：

- **品牌**：Logo 方块，22px。
- **快速访问**：撤销、重做、保存到我的曲谱、▾ 自定义。
  - 在任意功能区按钮上右键，可以「添加到快速访问工具栏」。
  - 自定义结果存在新增本机键 `musetab-qat`。
- **窗口页签**：见 §5。
- **保存状态**：显示「○ 仅存本机 · 存入我的曲谱」，可以直接点击存入。
- **发布**：全栏唯一的主色按钮。点击后先自动存入我的曲谱，再提交审核，一共 2 步，不用离开编辑器。
- **账号 ▾**：个人中心、创作者中心、谱库、外观、偏好设置、帮助、更新日志。

**功能区的规则**：

- **排布**：大按钮占两行；小按钮和记号格按列排两行；组名放在下面。
- **上下文组**：组按当前轨的记谱法隐藏，不做置灰。选项卡行右侧的「作用于 旋律1 · 简谱」始终说明当前作用对象。
- **放不下时**：从右往左把整组收成「组名 ▾」。1280 宽下实测，三种语境都不需要收组。
- **三种显示状态**：展开 / 单行 / 只留选项卡。
  - 切换方式：⌃ 按钮、Ctrl+F1，或双击选项卡。
  - 状态记在新本机键 `musetab-ribbon`。
  - 单行模式下，「开始」从 42 个按钮减到 27 个，「记号」从 49 个减到 12 个。
- **搜功能（Ctrl+/）**：
  - 覆盖 219 条命令，支持拼音首字母，比如输入 `ych` 找到延长号。
  - 拼音表在构建时生成，约 6KB，产品里不引入拼音库。
  - Ctrl+K 仍然留给和弦输入。
- **超级提示**：显示名称、快捷键、一句说明，以及「作用于」哪条轨。

### 3.3 页签为什么放在标题栏，不放在选项卡那一行

1. 文档页签和命令选项卡挤在同一行，又会出现「形状一样、意思不同、两处同时高亮」的老问题。
2. 1280 宽时，选项卡和搜索框已经占了约 750px，同一行只剩下放 2–3 个页签的位置。
3. 标题栏本来就要放品牌、快速访问和发布，并进页签不额外占高度。

### 3.4 现有顶栏按钮的去向

现有顶栏没有一个按钮丢失：

| 现有按钮 | 去向 |
|---|---|
| 智能 | 变成选项卡；≤1200 宽时仍是抽屉 |
| 新建 / 打开 | 文件后台，以及页签旁的「＋」 |
| 保存 / 存为文件 | 快速访问、保存状态、文件后台；Ctrl+S 仍然是存为文件 |
| 排版 / 预览 / 打印 | 「排版」和「输出」选项卡 |
| 预设 / 谱库 | 文件后台、账号菜单 |
| ◑ ◐ | 视图 › 外观 |
| 编辑栏 43 个控件 | 「开始」选项卡、快速访问、状态栏 |

**交互**：

- **点轨行**：切换当前音轨（`sel.row`、`sel.vi`），不再弹出盖住谱面的浮层。
- **眼睛开关切换记谱法**：组合不合法时提示「至少保留一种记谱法」。
- **六线谱**：改成一条动作行，修掉「看着是开关、点了却新建一条轨」的问题。
- **五线谱联排**：挂在组一级，并写明「全部吉他轨」，修掉开关作用范围不一致的问题。
- **状态钮**：显示 / 锁定 / 静音。
  - 「显示」关掉表示不刻版、不打印，需要新增可选字段，**待拍板**。
  - 「锁定」只在本窗口有效，不存盘。
  - 「静音」读写同一份 `mixer`；按住 Alt 点静音钮就是独奏。
  - 平时只显示非默认状态，当前行和悬停行才显示全部 4 个钮。这样轨名平时有 ≥100px 的宽度。
- **⋯ 菜单**：改名、音色、变调夹 / 调弦 / 谱号、导入 MIDI 到本轨、键盘 / 指板、独奏、上移 / 下移、删除。
- **其他操作**：同一分区内可以拖动排序；树结构用 `role=tree`，↑↓ 换轨；标题行的 ⋯ 里可以把全部轨一次改成简谱或五线谱（合唱常用）。
