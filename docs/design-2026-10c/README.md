# UI · 色调 · 视觉 · 交互动效全面升级方案 v4「画廊」（Apple 风格）

> **状态：已否决（2026-10-05 产品指示「否定这个设计，退回 Apple 风格之前的版本」）。** 曾于 v66.1–v66.3 发版，v66.4 已全部撤回；本目录仅存档备查，勿据此改界面。
> 参考：负责人提供的 DESIGN_4.md（Apple España：画廊式、雾白画布、产品悬浮、唯一实心蓝、胶囊按钮、毛玻璃顶栏）。
> 与同日 v3「谱面即展品」（Tesla，`docs/design-2026-10b/`）是**二选一**的两套方向；v3 里与风格无关的工程结论（谱面令牌隔离层、`svgResolveVars` 映射、打印分支重置、`--font-chrome` 字体防火墙、动效开关、测试断言清单、D7 风险）本方案全部沿用，下文只写差异。
> 专家团：视觉设计（首页精修稿）· 视觉系统映射 · 交互与动效。

## 1. 主张

**界面退成一面浅雾色的墙，谱面像展品一样悬浮其上；界面各就各位——导航在左、检查器在右、浮层从点击处长出来。**

- 画布 #F5F5F7，谱纸是直角白纸，只有照片式的极淡落影，没有边框。
- **实心蓝 #0071E3 每个视图只出现一处**（官网「开始制谱」、编辑器「导出」、看谱页「播放」、弹窗确认键）；**线和字的蓝 #0066CC** 给链接、描边按钮、当前工具与焦点。
- 区块之间靠底色轮换分隔（雾白 / 黑带 / 淡蓝洗色），不用分隔线。
- 弹簧动效只给界面框架；谱面内部不做任何逐元素动画。

## 5. 官网

- **信息顺序沿用修订 c**（首屏搜索＋谱面带 → 三谱同源 → 场景 → 最新上架 → 页脚），首页不做全屏展厅场景；视觉换成画廊式：区块底色轮换（雾白 / 黑带 / 雾白 / 淡蓝）、标题居中 600、每个区块一对胶囊按钮或一条「了解更多 ›」链接。
- 顶栏 44：白 72% 毛玻璃，压在黑带上时自动换深色。
- 场景与上架：白纸谱面无框悬浮，场景谱面统一 0.71 倍、裁在小节线；上架卡用引擎窄屏重排的页首。
- 页脚：雾白多列链接（找谱 / 制谱 / 考编·艺考·师范 / 学习 / 关于谱友圈）＋ 法务小字 ＋ 备案号。
- 垂类页：52 高吸顶本地导航，右侧一个实心蓝胶囊。
- 带 `?q=`、`#lib` 或小程序环境时直接进谱库模式（同 v3）。

## 8. 动效

| 令牌 | 值 | 用于 |
|---|---|---|
| `--ease-out` | cubic-bezier(.25,.1,.25,1)；悬停 100ms，退场 150ms | 按钮、菜单即现即收 |
| `--ease-snappy` | 弹簧（回弹 1.5%）340ms，`linear()` 采样；回退 cubic-bezier(.2,.9,.3,1) | popover 从箭头尖 .92→1 长出、分段白托、开关 |
| `--ease-smooth` | 弹簧（无回弹）420 / 590ms；回退 cubic-bezier(.32,.72,0,1) | 检查器、底部面板 420ms；手机上滑面板 590ms |
| 滚动驱动 | `animation-timeline: view()`，淡入并上移 24–28px，可逆 | 官网区块标题与谱面；黑带「三谱同源」可做粘性区块，按阈值交叉淡化切换谱种 |

- 弹簧只给界面框架；谱面、进度条、遮罩不用弹簧；谱面内部不做逐元素动画；播放高亮按小节跳变。
- 进场用 `@starting-style`；退场用「幽灵」克隆（去 id、inert）淡出，真节点同步删除，`closeModal` 等保持同步；不用 View Transitions（回调异步）。
- 系统「减弱动态」：位移与弹簧改为 150ms 交叉淡化。
- 自动化测试环境：弹簧、滚动驱动、幽灵克隆、自动隐藏计时器全部关闭；滚动驱动动画须 `animation:none`，否则视口外标题停在透明 0。面板停靠写进 `data-detent` 便于断言。
