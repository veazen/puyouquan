# 课程体系 2.0 方案：小节化 + 学/练/测三模块 + 五星闯关 + 多形态内容

> 状态：**已拍板执行中**（2026-09-04 提出并拍板）。产品选定：**① 代码块＝内容展示 ② 锁小节 ③ 视频＝自托管 mp4 ④ 进度上云（P3 做）⑤ 先《认识简谱》打样验收**。
> 进度：**P0 已发版（v61.9）**——数据模型 + 学习页 2.0 + 《认识简谱》16 小节打样。**P1 已发版（v62.0）**——课程独立页（站内 `?c=` + 服务端 `/course/<id>` SSR）、学习页与课程工作台双 UI 重设计、块级编辑器 + 发布前检查 + 小节级发布校验。**P2 游戏题型**（配对/排序/节奏敲击/听辨）、**P3 学习进度账号云同步**待排。
> 产品指示原文：「强化课程编辑功能以及当前的课程内容。内容要细化到小节，每个小节内容包含学习/练习/测试模块。练习需要打卡，测试满分 5 星，3 星以上才能解锁下一个章节。内容形式多样化，支持各种文档编辑/视频/代码。测试和练习可以是游戏形式。」

## 一、需求梳理（我对指示的理解）

| 指示 | 理解 | 现状差距（v61.8） |
|---|---|---|
| 内容细化到小节 | 课程 → 章 → **小节** 三级结构 | 现在只有 课程 → 章 两级 |
| 每小节含 学习/练习/测试 | 小节内固定三模块，学→练→测的学习闭环 | 章内是 内容点+任务+闯关题 的平铺 |
| 练习需要打卡 | 练习模块有独立打卡记录（不同于测试通关） | 打卡与闯关是同一个「完成」状态 |
| 测试满分 5 星，≥3 星解锁下一章节 | 星制 3→5，及格线 3 星，解锁链挂在测试上 | 现为 3 星制、≥60% 即通关 |
| 内容形式多样化：文档/视频/代码 | 学习模块由**内容块**组成：富文本、图片、视频、代码、互动谱、简谱谱例 | 现在只有纯文本行（内容点列表） |
| 测试和练习可以是游戏形式 | 除四选一外增加游戏题型（节奏敲击/听辨/排序/配对） | 只有四选一即判题 |

## 二、数据模型（红线安全：只增不改）

```
course.data.chapters[i] = {
  emoji, title, goal, points, task, links, quiz,   // ← v61.8 既有字段全部保留（老课程兼容渲染）
  sections: [                                      // ← 新增：小节数组（有此字段即走 2.0 渲染）
    { title: "小节标题",
      learn:    { blocks: [Block, …] },            // 学习模块：内容块序列
      practice: { blocks: [Block, …], game: Game?, checkin: true },   // 练习模块：说明块 + 可选游戏 + 打卡
      test:     { items: [Item, …] }               // 测试模块：题目序列（判分 → 5 星）
    }, …
  ]
}
```

**内容块 Block**（学习/练习说明通用，类型白名单）：

| type | 字段 | 渲染 | 备注 |
|---|---|---|---|
| `text` | md | 受限 Markdown 子集（标题/粗体/列表/引用）+ `[[简谱记号]]` | 白名单渲染，不存原始 HTML（XSS 红线） |
| `jp` | line | 整行简谱谱例（现有 jpTok 渲染器扩展：连音线/小节线） | 平台特色，出版样式 |
| `score` | pubId | 内嵌互动谱（观看页 iframe / 卡片跳转） | **谱课同源**＝护城河，学习页里直接跟谱播放/移调 |
| `image` | src, cap | 图片 + 说明 | URL 白名单（站内/图床，见待拍板 ③） |
| `video` | src 或 bvid | `<video>` 自托管 mp4 / B 站 iframe（域名白名单模板拼接，不存 embed 原文） | 见待拍板 ①③ |
| `code` | lang, src | 等宽代码块（复制按钮；高亮可后置） | 见待拍板 ① |

**测试题 Item**（题型渐进上线）：

| kind | 玩法 | 判分 | 期 |
|---|---|---|---|
| `choice` | 四选一（现有，即判+解析） | 对/错 | P0（沿用） |
| `pair` | 配对：记号 ↔ 名称 点选连线 | 全配对计对 | P2 |
| `order` | 排序：音符按时值/音高拖拽排队 | 序列全对计对 | P2 |
| `tap` | 节奏敲击：跟节拍器按谱面点击，判定时值误差 | 误差窗口内比例 | P2 |
| `ear` | 听辨：播放两音选高低/听节奏选谱（编辑器采样音色同源） | 对/错 | P2（CI 无声环境只测逻辑，假时钟口径） |

**五星判分**（测试）：`正确率 = 得分/满分`；错 0 = ★★★★★，错 1 = ★★★★，及格线 **≥70% = ★★★**，≥50% = ★★，≥30% = ★，否则不通过可无限重来；通关后可重测冲星（星级只升不降）。

**解锁链**（推荐口径，见待拍板 ②）：
- 小节内：学习（浏览即完成）→ 练习（打卡）→ 测试（≥3 星）
- 小节间：上一小节测试 ≥3 星 → 解锁下一小节
- 章之间：本章全部小节达标 → 解锁下一章（章卡显示 本章星数合计/满星）

**进度存储**：localStorage `pyq-learn-v1` 键名不变，值内新增 `sec:课程id` 兄弟键记小节级 {学习完成/打卡次数与日期/测试星级}——老用户既有进度原样有效（老课程按章级兼容映射）。账号级云同步列 P3（见待拍板 ④）。

## 三、课程编辑器强化（admin.html 工作台，本方案主体工程）

现状是「textarea 行格式」，撑不住块结构——升级为**结构化块编辑器**：

1. 章节列表 → 点开章 → **小节列表**（加/删/上下移/复制小节）
2. 小节编辑分 **学习 / 练习 / 测试 三页签**：
   - 学习：块列表——「＋加块」弹类型选单（文本/谱例/互动谱/图片/视频/代码），每块表单化编辑、上下移/删除、**实时预览**（右侧或折叠预览区，用与学习页同一渲染器）
   - 练习：说明块 + 打卡开关 + 游戏选择器（P2 起可选游戏模板+参数）
   - 测试：题目列表——题型选择 + 各题型专用表单（四选一沿用行格式或表单化；新题型均表单化），拖动排序
3. 发布校验强化：每小节三模块齐备（练习可空但需说明）、块类型/字段白名单、题目结构逐题校验，**错误定位到 章-节-块/题**；服务端 publish 同口径双保险
4. 「预览草稿」沿用 v61.8 通道（localStorage + ?preview=1），升级为小节级预览
5. 老课程一键升级助手：「按内容点拆小节」向导（每章 内容点→学习块、任务→练习、quiz→测试，编辑者再手工调整）

## 四、现有课程内容细化（内容工程）

- **《认识简谱》先打样**（P0）：6 章 → 约 14-16 小节。示例：第 3 章「音的长短①」拆为 3.1 什么是一拍（学：节拍器视频/谱例；练：跟拍打点游戏化打卡；测：时值四选一）/ 3.2 增时线（学：谱例+互动谱；练：数长音打卡；测：混合题）/ 3.3 综合读谱（学：小星星片段互动谱；练：跟谱唱打卡；测：章末大测）
- 吉他课（7 章）与幼儿课（6 章）在编辑器与打样验收后细化（见待拍板 ⑤），幼儿课练习偏亲子游戏化
- 每小节学习块 ≥3、测试题 ≥4（新五星制下题量建议 5-8 题/测）

## 六、待拍板问题（执行前需逐项确认）

1. **「代码」的含义**：A. 代码块（面向未来编程/技术类课程的等宽展示）；B. 嵌入代码（iframe embed 视频等）。方案默认 **A+受限 B**（B 只做域名白名单模板，不存原始 embed HTML）。
2. **解锁粒度**：方案按「小节测试 ≥3 星解锁下一小节；全章达标解锁下一章」。若产品本意是「只锁章、小节内自由」，改动很小，请指定。
3. **视频来源白名单**：自托管 mp4 / B 站 / 微信视频号（小程序 web-view 内三者限制不同），定哪几个？
4. **进度云同步**（P3）：要不要做账号级（跨设备续学、打卡 streak 真实统计）？不做则一直本机。
5. **吉他课/幼儿课**是否本轮一并细化（内容工作量约 ×3）？建议先《认识简谱》打样验收再扩。
6. P0+P1 建议连做（模型先行、编辑器紧随），P2 游戏题型可按优先级逐个上——执行顺序是否认可？
