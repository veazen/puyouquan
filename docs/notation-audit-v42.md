# 各谱类深度测试报告（notation-audit-v42）

> 5 位谱类制谱师 agent（六线谱 / 钢琴大谱表 / 简谱合唱 / 五线谱刻版 / 功能谱和弦）并行深测 · 审核对象：`muse-tab/index.html`（v42.1→v42.2）
> 方法：每类用 Playwright(chromium) 探针实测——注入本类记号丰富的曲例，读 `#score` innerHTML 计数 SVG 记号 / `getBoundingClientRect` 几何断言（非仅看图）/ `beatErrors()` 拍值校验，全程监听 pageerror。
> 红线：所有修复/建议均 **song 字段只增不改**。

产物：本轮同时为 **7 个此前无预设的谱类补齐了预设曲谱**（独奏/钢琴独奏/钢琴弹唱/歌谱/合唱/器乐五线谱/教学对照/纯和弦/功能谱进阶，共 9 首），谱库谱类覆盖由 4 类→**全 10 类**；新增 `tests/tv_presets.js` 回归（遍历 PRESETS 逐首渲染校验 + 谱类覆盖断言）。
