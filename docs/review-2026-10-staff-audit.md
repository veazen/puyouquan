# 五线谱全面复核（2026-10-28）

对象：v69.3 曲库导入的 10 首 OpenScore 艺术歌曲 + 新建面板 6 类五线谱。方法：转换保真 / 谱面展示 / 曲谱功能 / 新建录入 / 导出互通 5 个镜头 + 补漏一轮，58 个代理；每条发现由另一位复核者独立复现、尽量推翻。参照：MuseScore 3.2.3 对源谱的渲染。

结果：176 条成立（驳回 2），合并去重为 43 个问题（P1 11 / P2 27 / P3 5），其中 15 个的方案需要负责人拍板。报告页：https://claude.ai/artifact/FDwH2BsxNCmA3g7Gz3ETEK ；原始发现（含证据、根因、复核意见）存档在会话临时目录 audit/all.json，此文是可交接的合并版。

修复路线：v69.4 纠错一（导入 / 播放 / 导出，不加字段）→ v69.5 新增可选字段一批（待拍板）→ v69.6 纠错二（录入 / 新建 / 观看页）→ v69.7 刻版质量 → v69.8 同谱表双声部（原计划顺延）→ 第二批曲库 → S4 / S5。
