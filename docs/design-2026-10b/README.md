## 1. 主张

**界面只做无彩色的「说明牌」，谱面是唯一的展品。整屏只有一种彩色——蓝，只给「点火」的那一个动作。**

Tesla 的车是展品，页面只负责把车照亮；谱友圈的展品是**刻版引擎实出的谱面**。所以：

- 框架（顶栏、工具、侧栏、播放条）全部去色：白、灰、墨三级，零投影，发丝线分层。
- 唯一的蓝 `#3E6AE1`：官网＝「开始制谱」，编辑器＝「播放」，弹窗＝确认键；**同一时刻屏幕上只有一处蓝**。
- 谱面上的编辑笔（光标、选区、播放竖线）与 CTA 同一种蓝，语义统一为「你的动作落点」；播放小节带改无彩灰。
- 谱面内部不做任何动画；会动的只有说明牌。

## 4. 字体与形状

- 中文走系统字体栈（苹方 / 鸿蒙 / 雅黑 / Noto），不加载中文网络字体；Inter 只做拉丁与数字子集（约 25KB，自家域名）。新增 `--font-chrome` 只给界面白名单元素，谱面继承链不动。
- 字重只用 400 / 500（雅黑无 500 → 层级靠字号与颜色，选中态只变色不加粗，按钮宽度不再跳）。
- 字阶：官网 48 / 40 / 28 / 20 / 17 / 14 / 12；编辑器上限 20；中文最小 12px。数字用等宽数字。
- 圆角两档：4（按钮 / 输入 / chip）、8（卡片 / 弹窗 / 菜单）；谱纸直角；胶囊大圆角（61 处）退役。零投影。

- 谱纸通栏，去掉卡片外框；页首调 / 拍速用 20px 墨色数值当说明牌（原朱砂）。

## 8. 交互规范

- 层级：L1 蓝底（每视图 ≤1）· L2 墨底（非破坏性确认）· L3 幽灵 · L4 文字 / 图标。按钮高 40，手机 48。
- 状态：悬停 #000 5%、按下 12%；选中＝浅灰底＋1.5px 墨内描边（不改盒模型，几何断言不受影响）；焦点＝2px 墨外环偏移 2px。
- 确认与撤销：可撤销的操作先执行，提示条带「撤销」停 6 秒；删除曲谱改延迟提交；只有不可逆操作才弹窗（标题写后果、默认焦点「取消」、破坏性按钮白底红字红边）。替换 3 处浏览器原生确认框。
- 提示条：墨底白字，停留 max(4s, 字数×0.3s)，悬停暂停、排队不覆盖、`aria-live=polite`（现状固定 2.2s）。
- 保存：「保存」按钮改为状态胶囊（已存本机 / 已存「我的曲谱」/ 同步中 / 同步失败·重试）；存为文件、发布移进导出菜单。

## 9. 动效

原则：**展品不动，框架让路；慢入快出；一次只有一个焦点；关掉动效也完整**。

- 令牌：`--fx-press 80` `--fx-fast 140` `--fx-base 200` `--fx-panel 240` `--fx-hide 360` `--fx-reveal 600/错开 80`；进场 `cubic-bezier(.2,0,0,1)`，退场 `cubic-bezier(.4,0,1,1)`。
- 开关：`<head>` 首行脚本给 `html` 加 `fx` 类；`navigator.webdriver`（全部回归测试）、`?fx=0`、减弱动态下时长全为 0，**147 个套件读到的永远是终态**；新增 `tv_motion` 用 `?fx=1` 专测。
- 目录（P0/P1）：弹窗遮罩淡入＋面板上移 8px；浮层 / 提示条上移 4–6px；导航滚过首屏转白；官网第 2 屏起标题只进场一次；记谱法切换走白纸交叉淡化（≤320ms，节点过多自动降级）；演奏态界面退场；手机抽屉从底部滑入。
- 不做：谱面内逐元素动画（音符逐个出现、移调补间、小节带滑行）、视差 / 推近 / 滚动劫持、回弹弹簧、呼吸蓝钮、毛玻璃、自动轮播、数字滚动计数、任何需要推迟 DOM 移除的退场。
- 性能：首屏 LCP 桌面 ≤1.2s、4G 微信 ≤2.5s；满版图不常驻 will-change；动效不进入 `render()` 路径。
