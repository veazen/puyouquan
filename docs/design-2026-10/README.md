## 6. 组件与状态语言

- 圆角只用 6 / 12 / 16 / 999（外加 kbd 4）：现在编辑器和官网各有 22 种。
- **零阴影**：分层只靠 1px 线和色块。新增描边一律用 `box-shadow: inset 0 0 0 1px`，不改盒模型，避开几何断言。
- **唯一的选中语言**：薄荷底＋墨绿 1px 内描边＋字重 600。当前页签用下方一道荧光短划。
- 主按钮墨绿实底，r6；次按钮 1px 线；便签按钮薄荷/青/粉，同一行最多一个。焦点 2px 墨线外偏 2px，深色模式用黄。禁用 .45 透明＋title 写原因。
- 文档页签：当前页是纸面加顶部 3px 荧光索引条；未入库圆点用赤陶色。
- 提示条：薄荷便签条加 1px 墨线；可撤销的操作带「撤销」按钮、保留 6s；加 aria-live；排队显示不互相覆盖，位置让开播放条。
- 确认弹窗只给不可逆操作：后果写进标题，危险键赤陶描边放右侧，默认焦点在「取消」，替换 3 处原生 confirm()。
- 插画：墨绿单线（currentColor）。母题有摊开的谱本＋铅笔、荧光笔划过旋律、同一乐句三种写法、红笔圈音＋朱砂印、节拍器、声波变音符，每幅 ≤1.5 KB；不进 #paper，打印隐藏。

## 7. 谱面边界（排版专家）

**能改的只有两层**：谱纸底色、编辑覆盖层的颜色。刻版几何一处不动：Bravura 字形与 smg 缩放、PAGE_W / FIXED_A4 / MARGIN、线宽、连线、简谱 17/500 等字号字重。任何几何变化走 B4 流程（B4d 仍按负责人指示暂停）。

**成品一律白纸纯黑**：打印、存 PDF、预览、PNG、缩图、分享卡谱框。分享卡外框可以换奶油、墨绿、黄，谱框里面不动。

## 8. 交互与动效

**交互痛点与对策**（UX 实测）：
- 1280×800 下谱面只占视口 37%：二期外壳改版，目标 ≥55%，1440×900 下 ≥60%。
- 首屏 122 个控件主次不分：工具条随图层变化、低频操作收进下拉，目标 ≤80。
- 谱面所有状态都用同一个 --accent，只靠透明度区分：隔离层＋语义令牌。
- 提示条 2.2s 读不完、没法撤销、压住播放条：见第 6 节提示条规范。
- 垂类页的按钮只链到编辑器根目录：加 `?start=` 深链，配空状态便签卡。
- 「保存」有 4 层意思：顶栏保存胶囊四种状态（本机已存 / 已入库 / 同步中 / 同步失败·重试）。
- 手机编辑态固定控件占 30.7%：quickbar 替换图层轨而不是叠加，触控目标 ≥44px，弹窗改底部抽屉。
- 官网叙事和定位对不上：见 U-6。

**动效原则**：用笔触，不用弹簧，只用「划、贴、揭、点」四种动作；谱面 SVG 内零动画；进场快、退场即时。

**时长令牌**：
- 按下 80ms；悬停、菜单、提示条 140ms；弹窗 200ms；抽屉 280ms。
- 官网滚动出现 480ms；首屏马克笔划出 600ms，只播一次。

**开关**：prefers-reduced-motion 下降到 ≤120ms 淡入；`navigator.webdriver` 下自动关闭，147 个测试套件零改动。新增 tv_motion，约 8 项。

**不做**：逐音符动画、移调补间、View Transitions、面板宽高过渡、弹性过冲、3D、视差、遮罩模糊。
