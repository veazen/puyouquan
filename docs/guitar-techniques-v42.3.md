# 吉他谱三分类 · 演奏技巧符号与使用方法（v42.3）

> 新建向导把吉他谱拆为三类，独奏/指弹共享「六线谱＋五线谱联排」渲染基座，但按 `song.gtype` 加载**专属技法面板**（切换谱种即刷新）。所有技法均为 song **只增字段**，不影响既有谱。

## 三分类

| 谱种 | 新建入口 | docType / gtype | 定位 |
|---|---|---|---|
| 吉他弹唱谱 | 弹唱 | `guitar`（无 gtype） | 六线 TAB＋简谱＋歌词＋和弦图，标准弹唱版式 |
| 吉他独奏谱 | 独奏（电吉他） | `solo` + `gtype:'lead'` | 电吉他 solo，推弦/摇把/滑音/泛音/点弦/let ring |
| 指弹吉他谱 | 指弹 | `solo` + `gtype:'finger'` | 木吉他指弹，pima 右手指法/特殊调弦/打板/击勾滑 |

## 通用使用方法
- 在**六线谱声部**选中音符（Ctrl 可多选）→ 左栏「演奏技巧」面板点对应记号；再点同一记号可**取消**。
- **范围类记号**（揉弦 v / 闷音 P.M. / let ring）：Ctrl 选**首末两个**音符，记号覆盖整段范围。
- **打板**作用于「当前列」（无需选音符，选中列即可）；其余作用于选中音符。
- **特殊调弦**在新建独奏/指弹谱的第 2 步「定弦」下拉选择，谱首自动标注（如「Drop D」）。

## 电吉他技法（gtype='lead'）

| 记号 | 数据字段 | 谱面呈现 | 说明 |
|---|---|---|---|
| 推弦幅度 | `note.tech='b'` + `note.bAmt` | 弧线+目标圆圈，弧上标 ¼/½/full/1½ | Ctrl 选推弦音与目标音；GP 惯例 |
| 摇把·俯冲 | `note.bar='dive'` | 音符上方 `w/bar ↘` | 下压摇把音高俯冲 |
| 摇把·上滑入 | `note.bar='scoop'` | `w/bar ↗` | 先压后回滑入目标音 |
| 摇把·下点回弹 | `note.bar='dip'` | `w/bar ∨` | 快速下压回弹（V 形） |
| 摇把·颤音 | `note.bar='shake'` | `w/bar ≈` | 拍打摇把音高抖动 |
| 人工泛音 | `note.tech='hm'` + `hmT:'A'` | ◇ + `A.H.` | 按弦+右手食指触弦 |
| 拨片泛音 | `hmT:'P'` | ◇ + `P.H.` | 拨片与拇指侧同时触弦 |
| 点弦泛音 | `hmT:'T'` | ◇ + `T.H.` | 右手敲击高十二品处 |
| let ring | `note.tech='lr'`（范围） | `let ring----` 虚线 | 各音保持共鸣不切断 |

## 指弹技法（gtype='finger'）

| 记号 | 数据字段 | 谱面呈现 | 说明 |
|---|---|---|---|
| 右手拇指 | `note.rhFing='p'` | 品位数字下方小字 `p` | ④⑤⑥ 低音弦 |
| 右手食指 | `rhFing='i'` | `i` | ③ 弦 |
| 右手中指 | `rhFing='m'` | `m` | ② 弦 |
| 右手无名 | `rhFing='a'` | `a` | ① 弦 |
| 打板·低音区 | `col.perc='bass'` | TAB 中部 × + 上方「低」 | 掌根击低音侧面板 ≈ 底鼓 |
| 打板·高音区 | `col.perc='snare'` | × + 「高」 | 手指击高音侧 ≈ 军鼓 |
| 击板 golpe | `col.perc='golpe'` | × + 「G」 | 指甲敲击护板（弗拉门戈） |
| 特殊调弦 | `song.tuning=[…]` | 谱首标注 Drop D/DADGAD/Open G/Open D | `tuningLabel()` 匹配预设名 |
| let ring | `note.tech='lr'` | `let ring----` | 与电吉他共用 |

（击弦 h / 勾弦 p / 滑弦 sl·su·sd·ou·od / 揉弦 v / 泛音 hm / 点弦 tp / 闷音 P.M. 等基础技法三类通用，沿用既有 `EB_TECHS`。）

## 对照《乐谱记谱大全》完整度审计（`completeness-audit-v42.md`）的推进

本版落地了审计中电吉他/指弹的多项高价值缺口：
- 电吉他：摇把整族（原「整族缺失」）✅、泛音细分 A.H./P.H./T.H.（原「只有一个 hm」）✅、let ring 谱面虚线（原「播放有谱面无」）✅。
- 指弹：右手 pima 指法（原「最核心缺项、完全缺失」）✅、特殊调弦 Drop D/DADGAD/Open G（原「TUNING 硬编码」）✅、打板 body/golpe（原「无」，本版落地低音区/高音区/击板）✅。
- 通用：N.C. 无和弦（原「grep=0」）✅。

仍在排期（后续版本）：推弦回放 bend&release / 预推 pre-bend、竖琴/拍击泛音、交替拨弦/扫拨、左手指法数字、贝斯谱与鼓谱整类（战略大工程，待用户拍板）。
