## 用法

- 桌面页：Chrome 普通窗口，缩放 100%，窗口内宽 ≥1440，按 F11 全屏。屏幕不够宽就按 Ctrl+− 缩到能看全 1440×900 的画面。
- 手机页：直接在手机浏览器打开；或在电脑 Chrome 按 F12 → 手机模式 → 390×844。
- 已知与现状不一致、不问也不解释：输出条「分谱」带锁（分谱 v68.6 已上线）；原型上的字不是最终文案。
