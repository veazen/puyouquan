## ② 设计原则（硬指标，每版的验收门槛）

下表每条都能自动检查。「闸」指现有措辞闸 `deploy/check-wording.js` 加上新的「字数预算」规则：v68.4 起先只报告，v69.0 起改为拦截。「tv_textbudget」是新套件，复跑审计口径的 37 屏，以 v68.2 为基线，每版只降不升。

| # | 原则 | 硬指标 | 怎么检查 |
|---|---|---|---|
| **P1** | 说明句只在两种时候出现：**空谱**和**出错** | 常驻说明字每屏 ≤10、说明行 ≤1（读数、曲名不算）。空谱提示 ≤12 字、不带句读，落下第一个音就消失。出错提示只写「错在哪」，后面跟修复按钮 | tv_textbudget（37 屏） |
| **P2** | 字数上限 | 按钮、页签 ≤4 字（谱类名、乐器名等专名 ≤6）。菜单项 ≤6 字，**不带副标题**。悬停提示 = 名称 + 快捷键，名称 ≤12 字。提示条 ≤12 字，带一个动作（撤销 / 跳过去），有动作时停 ≥4 秒。例外：更新日志、特色功能等用户主动打开的长文 | 闸 + tv_textbudget |
| **P3** | **不指路** | 界面文案里不出现「行 1 / 行 2 / 左栏 / 右栏 / 底栏 / 上方 / ……页」这类位置词。需要指路时做成「带我去」：高亮真实控件，并展开它所在的面板 | 闸（正则）；v68.5 起禁止新增，存量随版清零 |
| **P4** | **一个功能一个家** | 每个功能 ≤1 个常驻位置 + ≤1 个菜单入口（命令面板、快捷键、启动台空状态卡不计）；同一屏不出现两个同名控件 | tv_textbudget 入口表（审计 functions 口径）+ 屏内同名检查 |
| **P5** | **强调纪律** | 工作区（行 2 以下）同时最多 1 个实底强调：书写时是悬浮条主按钮，输出时是「存 PDF」。行 1「发布」保持唯一的品牌色实底。「播放」改为中性样式 | 实底按钮计数：工作区 = 1，行 1 = 1 |
| **P6** | **用结果代替解释** | 三选一以上的选择（谱类、织体、节奏型、记谱法、导出格式、纸张）都配刻版缩略图或预览。预览没有副作用：song 逐字节不变，不进撤销，不触发保存，不进打印、导出和互动谱快照。悬停 ≥400ms 才出现，可在偏好里关掉 | 新套件 tv_preview |
| **P7** | **不挡墨迹、不跳版面** | 任何常驻或半常驻的层（预览角标、提示、空谱提示）与谱面墨迹的相交面积为 0；菜单类临时层除外。屏幕排版必须等于打印排版，不为工具让位。选中对象不引起谱面重排 | 几何断言（bbox 与墨迹相交）+ `#score` 逐字节对比 |
| **P8** | **键盘不变、焦点不抢** | 现有快捷键含义一个不改（1–7、0、+/−、Insert、Backspace、Ctrl+K、Enter 填词、Alt+B）。不设随情境变化的快捷键（不用 Ctrl+Enter）。提示、示范、发光期间，`document.activeElement` 不离开谱面。键盘写 32 小节旋律的按键数和耗时不高于 v68.2 | tv_matrix + 新套件 tv_keyflow |
| **P9** | **不只靠悬停、不打图标谜语** | 任何说明和预览都有点按的等价操作：触屏长按 0.5 秒 = 悬停，预览改成点一下出「写入 / 取消」。常用功能不能只在悬停时出现。非音乐功能的图标必须带 ≤4 字标签（简谱数字、♯♭、pp/mf、谱号这类音乐字形除外）。新图标首次点击识别率 ≥80% 才允许不带字。没存进「我的曲谱」时，保存状态必须带字 | tv_textbudget 纯图标白名单 + 手机套件 + 可用性测试 |

## ⑤ 分版本落地计划

### 原则

- **每版都能单独上线、单独回退。**
- **只动默认的新外壳**，CSS 都挂在 `body.flow` 下。`?shell=classic` 零差异：不建新节点，弹窗和原文案保留。
- **共享函数只加不改**，比如提示条文案改走 `toastKind`。改到共享函数的版本，两种外壳都跑 `tv_shellflow`、`tv_trktree`、`tv_modes`、`tv_flowdef`，对拍 `tests/shellflow_ref.json`。
- **回退开关**：从 S2 起，每版带一个只对本次访问生效的 `?next=0`（不写本机键），用于 A/B 对比和回滚。

### 评委列为「不可接受」的做法，本稿全部剔除

1. 「发布」降级为描边或次要按钮。
2. 为放工具而改变屏幕排版，或让屏幕排版和打印不一致。
3. 默认纯图标、系统自动降档，或删掉奏法、织体名等中文术语。
4. 默认收起左栏音轨树和记号面板。
5. 常驻或半常驻的层压墨迹；预览或占位混进打印和导出。
6. 随情境变化的快捷键；改动现有快捷键含义。
7. 只有悬停才能看到的说明或预览。
8. 主按钮自动执行，或在点下去之前换字。
9. 改动范围大的操作只靠一条转瞬即逝的提示条撤销。
10. 拿掉手机现有的编辑能力。
11. 删掉属性读数，或属性栏不能停靠。
12. 生成类操作丢掉范围参数；「修 N 处」越过锁定行。
13. 引导、示范或发光抢焦点、吞按键。
14. 导览和帮助删掉后没有「重看」入口。
15. 保存状态只用图标；步骤只显示编号；用「8ᵛᵃ / 8ᵛᵇ」表示单音移八度。
16. 只凭静态效果图上的「说明字 = 0」拍板。
