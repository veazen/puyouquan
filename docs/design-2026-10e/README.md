## 结论

推荐 **「按用途开谱 · 所见即所建」**：新建只问一件事——这份谱拿来做什么。

- **左栏按用途选**：9 个用途加空白谱，分「弹唱伴奏 / 课堂声乐 / 独奏乐队」三组，带 考编 · 师范 · 艺考 · 课堂 · 乐队 标签和各自的默认值（例如儿歌弹唱 1=F、2/4、♩=104、8 小节、2 段词）。
- **中栏看见成品**：刻版引擎现场排出的真实预览；上方一排「要哪几种谱」（简谱 / 五线谱 / 六线谱 / 大谱表 / 和弦）可点亮、熄灭，和左栏用途是同一份设置——三记谱法同源第一次出现在用户第一眼。
- **右栏参数全有默认值**，每个值旁边写「依据」（场景惯例 / 你改的 / 按文件 / 默认），回车就建。
- **建好在新窗口打开，原谱保留**；谱面上方的谱型条把人带到下一步：写旋律 → 一键配伴奏（直接填进当前谱，可撤销）→ 选织体。
- **导入、AI 转谱结果、示例做同款**都在同一个面板的「从已有音乐」里：真解析文件，写明依据，选「做成哪种谱」再导入。
- **图标**：风格 1「记谱缩略」为唯一来源，加谱层语法与 16px 微缩母版，共 101 枚。

## 推荐理由

1. **以方向 B 为骨架**（owner 8.4、design 7.9 两票推荐）。它是唯一既不新增 song 字段、又把「三记谱法同源＋出版级刻版」两条护城河放上第一屏的方案；14 种谱行组合全部落到现有 `createSong`。
2. **把方向 A 的「按用途」提到首屏**（teacher 评 A 8.2）。老师按用途找谱，不按记谱法找。场景＝谱行组合＋默认值，点场景就是点亮对应的谱，两种入口不打架。
3. **落地不停在空谱**。A 的起步条和 C 的谱型条合成一条，锚在谱纸宽度内，不压左栏和歌词抽屉；按钮直接调用现有的智能配谱和把位生成。
4. **C 只取能落地的四样**：依据、空谱无损换谱类、深链、手机「发到电脑继续」。一句话推断不进首屏（复测 22 条老师说法，曲名错 8 条）。
5. **外观不动**：只用 v66.5「极光靛紫」令牌，沿用现有外壳；不做纸本拟物、展厅大图、画廊留白，与三套已否决方向（`docs/design-2026-10/`、`10b/`、`10c/`）区分开。

## 最终流程（逐屏）

总览：`flow.png`；拼板：`boards/3-推荐流程-电脑.jpg`、`boards/4-推荐流程-手机.jpg`、`boards/5-深色.jpg`。截图全部是把方案注入真实编辑器后的实拍，浅色、深色各一份（文件名末尾 `-light` / `-dark`）。

### 0 · 入口：一个面板，所有入口

- 顶栏「新建」（Alt+N）＋右侧「▾」快捷菜单；页签条「＋」；启动台「开始一份谱」；文件拖到窗口任意处；官网垂类页深链。
- 不用 Ctrl+N（浏览器保留，网页拦不住，见 `index.html` L14467）、不用 Ctrl/⌘+K（已是和弦快速输入，L14477）。
- 启动台（`shots/F01-startpad-desk-*`）：主卡「开始一份谱」，旁边「按上次」「从已有音乐」，下面常用用途一点直达（吉他弹唱、钢琴即兴伴奏 · 考编、教学对照谱 · 课堂、视唱练耳谱例 · 艺考、儿歌弹唱 · 师范）。「继续上次编辑」只在有自己保存过的谱时出现，不再把示例谱当成上次编辑（修 P2-24）。

- **中栏**：「将建成 · 钢琴伴奏歌谱」＋用途名；一句说明；「要哪几种谱」五个开关；预览；一行「简谱 · 五线谱 · 六线谱同一份数据，建好后随时互切」。预览右侧的行标按引擎排出的行位置对齐，不编号，只在要先写的那一行标「从这行开始写」（修 B 的 ①② 与版面顺序不一致）。
- **右栏**：曲名 → 旋律用 简谱 | 五线谱（只在能互换的用途出现；吉他弹唱、教学对照、视唱等写明固定用什么）→ 用途变体 → 调（大调 / 小调分组，小调按关系大调记谱）· 拍号 · 速度 → **依据**（实线＝你改的 / 按文件，虚线＝场景惯例，灰＝默认）→ 更多设置（小节数、歌词段数、定弦、变调夹）。
- **底栏**：键盘提示、「新窗口打开 · 当前谱保留」、主按钮「创建 · {谱名}」。
- **键盘**：用途列表是 listbox（roving tabindex），↑↓ 选、Enter 建、1–5 开关五种谱、Esc 关；双击用途直接建。

### 2 · 冲突不静默（`F06-panel-hover`、`F07-panel-conflict`）

- 鼠标悬停或键盘聚焦在某个谱上时，提示行先预告结果，例如「点亮『钢琴大谱表』→ 钢琴伴奏歌谱（将换下『六线谱』）」。
- 点下去后，提示条说明原因（「六线谱和钢琴大谱表是两种乐器……」），并给 6 秒「撤销」。
- 叠加规则沿用 B：5 种谱 × 14 种起点＝70 种点选全部落到合法组合。

### 3 · 从已有音乐（`F10-import-ai`、`F11-import-read`、`F12-import-acc`、`F13-import-landed`）

- 左栏来源：打开或导入文件（MusicXML · Guitar Pro · MIDI · 谱友圈文件）、整理 AI 转谱结果、示例做同款、接着做、录音转谱（暂停中）、图片识谱（规划中）。
- 读文件用编辑器真解析器（`importMusicXML` + `mxlKeyPost`）。依据逐条写：「1=C 按文件」「4/4 · ♩=66 按文件」「1 声部 · 有歌词 · 五线谱 按内容」；文件没写调号时写「按音符内容推断」。AI 转谱来源默认推荐「教学对照谱」。
- 「做成哪种谱」6 选 1：按原文件 / 转成简谱 / 五线＋简谱对照 / 配钢琴伴奏 / 生成吉他弹唱 / 标级数和弦；选哪个，预览立刻换成哪个（真实刻版）。
- 文件的 `<encoding><software>` 写着转谱软件名（实测样例「AI Music Transcriber 2.1」）时，自动按 AI 转谱结果处理，依据里写明来源。
- 老师任务「AI MusicXML 转五线＋简谱对照」：新建 → 从已有音乐 → 选择文件 → 导入，**4 次**（现状 5 次且要靠隐藏的「左轨旋律 → 点亮 1 2」）。
- MIDI、Guitar Pro 读进来后直接转交现有的选轨对话框（`showMidiImport`、`showGPTrackModal`），面板里不重做选轨与量化（见拍板 2）。
- 录音、图片不支持时说明原因，并引导「用 AI 转谱工具导出 MusicXML 再拖进来」。

### 4 · 落地：谱型条＋起步条（`F14`、`F15`、`F16`、`F17`、`F19`、`F20`）

- 新谱在新窗口打开；谱面上方一条谱型条，宽度与谱纸一致、贴着谱纸顶部，不压左栏和歌词抽屉（修 C 的 real-08）。
- 内容：谱类图标＋谱名 ▾（换谱类）· 旋律用 简谱 | 五线谱 · 起步条 · 主按钮 · 收起。
- 钢琴伴奏歌谱：①写旋律 → ②配和弦与伴奏 → ③选织体。写完旋律后②亮起「一键配伴奏」，打开现有智能配谱弹窗，新增并默认选中「填进当前谱（简谱旋律＋大谱表伴奏，可撤销）」（修 teacher A-3）；弹窗打开时收起 toast（修 A-7）。
- 吉他弹唱「先写旋律」：①写旋律 → ②生成六线谱 → ③调把位与扫弦。生成时复用建谱时那条空吉他轨，不再多出一行空 TAB（修 A-6，`F20` 左栏只剩「吉他·旋律1」）。
- 其他谱类：起步条换成一句操作提示（如教学对照谱「在五线谱或简谱行输入都行，另一行同步」）。
- 谱型条状态记在内存里（按窗口），不写进 song；收起后本次不再出现。

### 5 · 换谱类（`F18-switch-menu`、`F21-switch-empty`）

- 空谱：任意换，按同样的曲名、调、拍号、速度重建（无损）。
- 已有内容：只给不动音符的换法（直接换，可撤销），例如钢琴伴奏歌谱 ⇄ 五线谱版 ⇄ 教学对照谱（含伴奏）；其余「另建一份」，把旋律（含歌词、和弦）带到新窗口，原谱保留；六线谱 ⇄ 钢琴这类不同源的写明「不可换」及原因。

### 6 · 手机 390（`M01`–`M08`）

- 启动台补上「开始一份谱」主卡（修 A-8）；按用途列表每行 64px，只用图标不用小样张（`M02`）。
- 详情页：预览＋参数＋依据，主按钮常驻底部、高 52px（`M03`、`M04`）。10 个用途逐个实测：主按钮全部可见、无横向滚动。
- 默认遵守「手机以看谱为主」：主按钮是「发到电脑继续」，复制带用途与调拍的链接（`M05`），例如 `https://zhipu.puyouquan.com/?new=kids&key=F&meter=2/4&tempo=104&acc=mel&mel=J`；手机上导入的文件以看谱模式打开（`M06`）。
- 若拍板开放手机新建：主按钮换成「创建」，落地显示起步卡（`M07`、`M08`）。

### 7 · 深链

统一成一种参数：`?new=<用途>`，可带 `key`（小调加 m，如 `Fm`）、`meter`、`tempo`、`title`、各用途变体，自选记谱法再加 `rows=JG` 这类谱行代码。合并 C 的 `?start=钢琴伴奏` 与 B 的 `?new=JG`。官网垂类页建议：考编 / 即兴伴奏 `?new=pacc`，师范 `?new=kids`，艺考 `?new=sight`，课堂 `?new=teach`。

源：`src/icons/gen.js`（底稿＝`nf/icons` 风格 1）→ `icons/*.svg`（101 枚，母版按原生尺寸出）、`icons/pq-icons.js`（运行时 `pqIcon(key, size)`）、`data/icons-manifest.json`（语义、用处、替换的旧图标）。图标表 `icons.png`，拼板 `boards/6-图标体系.jpg`。

- **分组**：谱类 17（含新增 钢琴伴奏歌谱、五线谱和弦谱、儿歌、视唱、自选记谱法）· 16px 微缩母版 14 · 记谱法 / 谱行 12 · 谱号 3 · 来源 13 · 模板 2 · 动作 16 · 乐器 24。
- **谱层语法**（嫁接 C）：简谱层、五线层、六线层、大谱表层、和弦名层、歌词层各有一组固定几何；谱类图标＝自上而下叠谱层。例如钢琴伴奏歌谱＝简谱层＋大谱表层，钢琴弹唱谱＝和弦名层＋大谱表层，两者只差顶层——一眼看出「有没有旋律」。
- **线宽**（取 A 的分档，物理像素恒定）：

| 显示尺寸 | 主笔 | 谱线 | 母版 |
|---|---|---|---|
| ≤16px | 1.25 | 1.0 | 16 网格微缩 |
| 17–22px | 1.5 | 1.0 | 24 网格 |
| 23–34px | 1.75 | 1.25 | 24 网格 |
| ≥35px | 2.0 | 1.5 | 24 网格 |

  现状同一线宽缩放后实际 0.90–2.40px。24 网格活区 2–22，五线 / 六线横线落在 n+.5，1x 下是实线。

## 风险

1. **桌面信息量变多**：首屏 313 字 / 29 个控件（现状 259 / 15）。缓解：做选择只需读用途名；描述压到一行；紧凑档隐藏说明。
2. **借谱渲染的正式化**：要动 `render()` 入口，必须带上离屏不变量断言；若排期紧，第 1 版可先不带预览、只上用途与参数（预览留位）。
3. **谱名表与谱库口径**：编辑器先改，谱库与服务端二期同步，过渡期同一份谱在编辑器与谱库叫法可能不同（例如「钢琴伴奏歌谱」在谱库仍显示「简谱歌谱」）。
4. **钢琴弹唱的词义**：师范生说的「钢琴弹唱」含旋律，产品里的「钢琴弹唱谱」是纯伴奏；本稿用「钢琴伴奏歌谱」与「钢琴弹唱谱（纯伴奏）」并存，见拍板 4。
5. **2/4 儿歌织体缺口**：儿歌弹唱默认 2/4，一键配伴奏目前落到「进行曲 / 波尔卡 2/4」，不是「儿歌伴奏」，第 3 版补。
6. **一键配伴奏「填进当前谱」**改变了原「另开窗口」习惯；保留原选项，只在钢琴伴奏歌谱里默认选它。
7. **手机端**：默认不开放新建；若开放，手机录谱体验（键盘遮挡、逐弦精修）需另行评估。
8. **原型的局限**：`proto.html` 预览是 264 份预先排好的真实刻版，没预渲染的组合按同谱行默认调拍显示并注明；导入演示固定用《送别（AI 转谱）》。以实拍为准。
