## 5. 各方向长处、硬伤与去向

### A 按成品开谱

- **长处**：第一屏就是用途，带考编 / 师范 / 艺考 / 课堂标签，10 秒内能开始写；「从哪写起：直接写六线谱 / 先写旋律」是老师的说法；起步条直接调用真实配伴奏与生成六线谱；手机能完整新建；59/59 组合往返一致；「新建 ▾」2 次点击。
- **硬伤**：9 张样张单张只占 1.9% 视口，手机上小到看不清；新增 `song.scene`；导入不能选做成哪种谱，「整理 AI 转谱结果」是写死的假视图；起步条文案在 1280 下被截断；竖排组名读不出；生成六线谱后多出一条空吉他轨；配伴奏弹窗被 toast 压住；1024 宽下场景名被截。
- **去向**：场景层、默认值、起步条、「新建 ▾」、Alt+N / Alt+Shift+N、示例做同款、AI 转谱入口、手机列表 → 详情、线宽分档全部采用；样张、`song.scene`、竖排组名不采用。

### B 记谱法优先＋实时谱样

- **长处**：五种记谱叠加，14 种组合全部映射到现有 `createSong`，不新增任何 song 字段；引擎实时刻版预览；冲突自动换行并说明原因；500 串随机操作泄漏 0；顺手修掉五线谱合唱谱只有第 1 声部是五线谱、五线谱旋律＋伴奏填词后漂成合唱谱两处；导入后的常用转换正中老师需求。
- **硬伤**：第一眼只有「简谱 / 五线谱 / 六线谱」，考编老师找不到「即兴伴奏」；常用组合压在谱样下方、没有标签；建好后只有一条 toast；冲突替换是静默的；Ctrl+N / Ctrl+⇧+N 网页拦不住且实际未绑定；预览靠临时换全局 song（改 11 个全局量和 `#paper` 样式）；谱样编号与版面顺序不一致；自造词「谱行 / 落笔行 / 谱样」；手机常用组合 10 个里 8 个在屏外；深色下谱行缩略图是白块；原型用的是简化假顶栏。
- **去向**：谱行引擎（骨架）、实时预览、导入常用转换、冲突说明、`musetab-nw-last` 采用；预览改成 `render()` 离屏目标；常用组合升级为左栏「按用途」；冲突改为悬停预告＋撤销；快捷键改 Alt+N；编号去掉；自造词换成「要哪几种谱」「从哪写起」「预览」「自选记谱法」；谱行开关只用记谱法图标。

### C 一步开始＋智能推断

- **长处**：可解释回执（每个值从哪来）；空谱可以无损换谱类；有内容时只给不动音符的换法；「钢琴伴奏」不再落到空谱；官网深链预填；手机「发到电脑继续」；「接着做」排除示例谱。
- **硬伤**：22 条真实师生说法复测，曲名错 8 条、谱类错 1 条、调错 1 条；回执浮层选完后 `state.sel` 跳到下一行，回车建成尤克里里谱；带词的五线谱被识别成「没有歌词」；「另建一份」未实现；新增 `song.kind` 形成第二个谱类真源；谱型条压住左侧歌词抽屉；`openStart` 固定用弹层，390 宽下文字被截；Ctrl/⌘+K 已是和弦快速输入；谱样面积 0%。
- **去向**：依据、谱型条（锚定谱纸、状态不进 song）、空谱无损换谱类、深链（与 B 的 `?new=` 合并）、发到电脑继续、「接着做」排除示例采用；一句话推断、`song.kind`、Ctrl+K 不采用。曲名框只解析确定写法的调拍速度（如「送别 F调 3/4」）可放到以后，前提是先修好曲名污染与「降E」识别。

**最终图标集的合并规则**：

1. 风格 1 为唯一来源（`final/src/icons/gen.js`），构图嫁接 C 的「谱层语法」——同一谱层在所有谱类图标里几何一致，谱类＝自上而下叠谱层，与面板预览同构。
2. 16px 一律用专用微缩母版（风格 1 的 type16 加 B 的「16 母版只用于 16px」规则）。
3. 线宽取 A 的分档：≤16px 1.25 / 1.0，17–22px 1.5 / 1.0，23–34px 1.75 / 1.25，更大 2.0 / 1.5（物理像素恒定）。
4. 上线前修掉三处：吉他弹唱 / 尤克里里（横宽 6 弦格＋歌词层 vs 竖长 4 弦格＋空弦圈）、钢琴独奏 / 钢琴弹唱（整高大谱表 vs 和弦名层＋半高大谱表）、合唱与钢琴独奏 16px 减笔。
5. teacher 提议嫁接 A 的 4 枚：视唱采用 A 的音叉（风格 1 原本没有视唱图标）；吉他 / 尤克里里与钢琴两组 16px 问题已在风格 1 内用格子比例与谱层差异解决，不再引入琴身与键盘轮廓（它们是乐器图标，放进谱类会一图多义）；器乐五线谱 16px 保留风格 1 的四线＋符头。
6. 新增：钢琴伴奏歌谱（简谱层＋大谱表层）、五线谱和弦谱（和弦名层＋五线层）、儿歌（星形＋简谱层＋大谱表层）、自选记谱法、和弦行、五线＋简谱对照、伴奏织体、AI 转谱结果、音频、图片、以及展开 / 关闭 / 已选 / 换谱类 / 撤销 / 更多设置 / 链接 / 说明 / 回车 / 返回 / 下一步 共 24 枚；总数 101。
