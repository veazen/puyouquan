   已拍板、允许变化的只有这几项（§7 列全）：E8 纯五线谱页头；F3 老谱里已有的跳音 / 延长号 / 渐强渐弱 / 踏板记号开始影响播放与 MIDI；T9 五线谱倚音按时值画符尾 / 符杠；N8 录入时值沿用与「删除」按钮语义。
3. **旧版本打开新谱**：旧页面忽略不认识的字段，退回 v69.7 的显示 / 播放；每个字段在「老版本」一栏写明退化结果。旧页面增删声部会让按下标的新数组错位 → migrate 规整（§3.6）。
4. **两套外壳**：所有入口落在共享函数 / 共享弹窗里，新旧外壳同一结果；新外壳提示用 `toastSay`，旧外壳原文不动；新文字守字数预算（按钮 ≤4 字、菜单项 ≤6 字不带副标题、悬停 ≤12 字、不写位置词），跑 `node deploy/check-wording.js` 与 `tv_textbudget`。
5. **清洗白名单一次加齐**：第 0 步（§4）先单独提交，四组都从它开分支，避免四组改同一行。
6. **测试口径**：每组新套件两外壳各跑一遍（测旧布局的钉 `?shell=classic`）；修前红 / 修后绿一律用数值断言（`window.__pyqGeom` 的 `data-g` 几何、播放事件记录器、导出文本）；老谱零差异用既有基线证（`tests/shellflow_ref.json` 16 预设 / `tv_trktree` T23、`parts_ref.json`、`pgbrk_ref.json`）；每组都跑语法闸 + 措辞闸 + `tv_matrix.js`。

## 3. 逐项规格

### 3.1 `col.syl` 歌词音节（A · T10）

**写入规范**：长度 ≤ `lyrics.length`；末尾的 0 截掉，全 0 删键；只在该段歌词非空时有效。所有歌词写入点改走新函数 `lyrSet(col, li, text, code)`（文本空 → 同下标清 0）。
「下一个音节」＝同声部、同段、往后第一个 `lyrics[li]` 非空的列（可跨小节、跨行）；「拖腔终点」＝从本列往后、到下一个本段有词的列或休止之前的最后一个音（含连音线续音）。

| 读写点 | 规则 |
|---|---|
| MusicXML 导入（`importMusicXML`，锚点 `[...el.querySelectorAll(':scope > lyric')].forEach`） | `<syllabic>` begin / middle → 位 1；`<extend/>`（无 type 或 `type="start"`）→ 位 2。只有 `<extend type="stop|continue"/>`、没有 `<text>` 的 `<lyric>` 不建空词、不计 skip。多 `<text>` / elision 拼接（v69.4 A6）不变，syllabic 取该 lyric 里最后一个 `<syllabic>` |
| MusicXML 导出（`exportMusicXML`，锚点 `<syllabic>single</syllabic>`） | 每声部每段记「上一音节带位 1」：`prev ? (cur&1?'middle':'end') : (cur&1?'begin':'single')`；位 2 在 `<text>` 后写 `<extend type="start"/>`，拖腔终点那个音写只含 `<extend type="stop"/>` 的同号 `<lyric>`（MuseScore 同写法）。没有 syl 的谱输出逐字节不变 |
| MIDI | 不涉及（导出不写歌词事件） |
| 五线谱 / 简谱刻版（`renderCore` 歌词循环，锚点 `(col.lyrics||[]).forEach((ly,li)=>{`） | 歌词循环里只登记每个音节的墨迹左右缘（`lyrSplit` 同一份量宽）；每个（系统 × 声部）画完后调一次 `lyrConnSVG` 画连接符。连字符：`<line>` 线宽 1.1、y＝歌词基线 −5.2、长 min(7, 空隙 −4)，居中于两音节墨迹之间；空隙 <6 不画；空隙 >40 每 30px 重复一个；跨行时只在本行末音节后画一个（到行尾前 4px）。延长线：线宽 0.9、y＝基线 +1，自音节右缘 +1.5 到拖腔终点的符头右缘（五线谱）/ 数字右缘（简谱）；长度 <4 不画；跨行续到行尾、下一行自首小节起续到终点。`data-g` 新类别 `lyrhy` / `lyrext`；`avInk` 把这两类记进歌词层（锚点 `k==='lyr' || k==='lyrp' || k==='verse'`），不当墨迹去推力度 |
| 排版（`measureLayout`，锚点 `if(isVox){ const lw = lyrW(c);`） | 带位 1 的音节右半宽 + `LYR_HY`（6），保证连字符最小空隙；只对带位 1 的列加，老谱 0 差异 |
| 播放 | 不涉及 |
| 录入（`smartTokenize` / `lyrBoxCommit` / `showLyricMenu`） | 「hap-py」：字母词后紧跟的 `-` → hap 带位 1（现在已分音节，只是没存）。拉丁 / 希腊 / 西里尔词后单独的 `_`（「love _」「love_ me」）→ 前一音节加位 2，**仍跳过一个音**（v69.6 规则不变）；中文 / 日文 / 韩文后的 `_` 照旧只跳过（中文歌本拖腔不画延长线）；前后有空格的 `-` 照旧只跳过。token 只**加**属性 `hy` / `ext`，`t` / `v` 不变（`tv_v696in` I2a 的序列化不受影响）。`showLyricMenu` 的移位 / 删除让 syl 跟着文字一起搬 |

### 3.2 `grace.slash` 倚音斜线（A · T9；播放在 B）

- `normGrace(g)` 只在 `g.slash===false` 时带出 `slash:false`——所有经 `normGrace` 再写回的路径（`showGraceMenu` 的 `col[key]=g` 等）不丢。新加的倚音不写 slash（短倚音，同今）。
- **五线谱刻版**（`renderCore` 内 `stGrace`）：`slash!==false` 照画斜线；同时（T9 刻版项）按 `g.dur` 画符尾 / 符杠——单个倚音 dur 8 / 16 / 32 画 `flag8thUp` / `flag16thUp` / `flag32ndUp`（0.62 倍）；多个倚音符杠条数 1 / 2 / 3（杠距 0.75 线距 × 0.62），符干够到符杠。单个带符尾的倚音占位 +2.5（`measureLayout` 里倚音宽那一处，只在五线谱行）。简谱 `drawGrace` 不变（简谱无斜线写法）。
- **MusicXML**：导入 `<grace>` 无 slash 属性或 `slash="no"` → `slash:false`；`slash="yes"` → 不写。导出 `slash===false` → `<grace/>`，否则 `<grace slash="yes"/>`（今）。自家导出的谱再导入不变。六线谱倚音不读不写。
- **播放（B 读取）**：`slash===false` 且只有 1 个倚音 → 拍上奏出、占倚音时值（≤ 主音一半），主音推后同样长；多个倚音或无键 → 老口径（拍前短促）。MIDI 同。
- **录入 UI**：`showGraceMenu` 加一对按钮「短倚音 / 长倚音」（3 字，两外壳同一弹窗）。
- 清洗：布尔值，不进表。曲库重建后复核的 11 个无斜线倚音变长倚音。
- **老谱 / 老版本**：老谱无键 → 斜线照画；符尾 / 符杠是刻版修正，所有五线谱倚音观感变（§7）。旧版本打开新谱：长倚音也画斜线（＝v69.7）。
- **测试（tv_v698lyr G 段）**：G1 导入 `<grace/>` → `slash:false`、`<grace slash="yes"/>` → 无键；G2 导出往返；G3 几何：长倚音斜线元素 0 个、短倚音 1 个；单个十六分倚音有 `flag16thUp`、两音十六分有 2 道符杠（修前符尾 0 / 符杠 1，红）；G4 弹窗切换长 / 短写入 / 删除 slash，normGrace 往返不丢。

### 3.3 `mea.tempos` 曲中速度 + E8 速度位置（B · T6 / E8）

**元素**：`{q, bpm, tempoUnit?, text?, hide?}`
- `q`：自小节起点的偏移，以四分音符为单位（≥0）；`bpm`：按 `tempoUnit` 计（导入夹 20–300，界面 30–240）；`tempoUnit`：`'q'` / `'e'` / `'dq'`，缺省 `'q'`；`text`：印在 ♩= 前的速度文字（≤40 字，如 Più mosso）；`hide:true`：只进播放不印（OpenScore 用来模拟渐慢、没印出来的 `<sound tempo>`）。
- **生效规则**：按谱面线性位置取「最后一个 ≤ (mi, q) 的点」，没有就是 `song.tempo` / `tempoUnitOf(song)`——所以 D.C. 跳回开头自然回到初速。第 0 小节 `q=0` 的点不存（并进 `song.tempo`）。`q` ≥ 本小节实际长度的点（改拍号后的残留）按小节末处理。纯函数 `tempoPtsOf(s)`（线性化全部点）/ `tempoAt(s, mi, q)`。
- 插删整小节随小节走；插删音符不动 `q`（锚在拍位上，不锚在列上）；分谱 `partSong` 深拷贝自带，每一份都印。

| 读写点 | 规则 |
|---|---|
| MusicXML 导入（direction 段，锚点 `return;   // 其余 direction（metronome/rehearsal 等）另行处理`） | 起始速度事件（v69.4 A2 的 `best`）以外，带 `<metronome>` 或 `<sound tempo>` 的 direction（及裸 `<sound tempo>`）→ 点 `(mi2, (tcur+offset)/div)`；`mtOf` 从起始速度 IIFE 里提到 importMusicXML 作用域共用。有 metronome → bpm / tempoUnit，同一 direction 的 words 进 `text`（不再进 anno / dyn）；只有 sound tempo → `bpm`（四分口径）+ `hide:true`。各 part 去重（同小节 \|Δq\|<1e-3 留第一个） |
| MusicXML 导出 | 主 part（P1）在 q 处写 `<direction placement="above">[words]<metronome>…<sound tempo/></direction>`（同起始 `tempoXML` 的写法）；`hide` → 只写裸 `<sound tempo="…"/>`。落在第 0 声部第一个起拍 ≥q 的音之前，不正好在列上时写 `<offset>`。没有 tempos 的谱逐字节不变 |

### 3.9 录入：时值沿用 + Delete 统一（D · N8，无新字段）

**时值沿用**
- 状态 `ENTRY_DUR`（内存，`{s:song, dur}`，不进 song、不写 localStorage）：单格 `setDur(d)`（不在选区批量、不在 `meaUnderOk` 小节）时记下 d；`keyKeepReset()` 里一并清（打开 / 新建 / 切页签 / 观看页进出都已调它）。
- 生效：往**空格**落音（`setDeg` 里 `!was && d`、`setFret` 往空列写品位、谱面鼠标点音进空格）且 `ENTRY_DUR.dur` ≠ 该格时值时，先按 `setDur` 对空格的同一套规则改这一格（改短 `fillRestsAfter` 补同值空列、改长 `absorbRestsAfter` 吸收其后空白列；抽成 `durOnBlank`，`setDur` 与沿用共用），再落音。改长吸收不够（会超拍）就不改、按空格原时值落；连音组内（`c.tup`）不改。
- 不沿用的：已有音的格（改音高不动时值）；附点（每个音单独按「.」——附点沿用会让最常见的「附点四分 + 八分」每一步都要撤附点）；弱起 / 不完整小节 / 散拍（那里的时值键定的是小节容量，v68.8 收尾 IN-1 口径）。
- 显示：光标在空格上时，时值按钮（旧外壳 `#eb-dur`、新外壳悬浮条）按 `ENTRY_DUR` 亮，看得出下一个音会是几分。
- 为什么改得动 v68.8 的「不做沿用」：v68.8 顾虑的是「熟手逐音按时值键的结果」与「时值键含义」。按本规则，每个音前都按时值键（或落音后再按时值键改刚落的音）的打法结果逐字节不变（下文 V2 用 tv_v688 / tv_v696in 的按键序列证）；弱起真实打法（tv_v688 FX1b「Delete×3 → e / r → 5 1 1 5 …」、pk4 / pk8）因弱起小节不记沿用而不变。变的只有「按一次时值键后连续落音」——这正是复核 N8 要的。

**Delete 统一**
- 现状：键盘 Delete → `delColumn`（删格，删掉的时值并进相邻音；弱起 / 不完整小节 / 散拍直接删，v69.6 I5；只剩一格时改成整格休止）；行 2「删除」按钮 `#eb-delcol2` → `deleteNote`（直接删、小节变欠拍、时值检查变红；只剩一格时拒绝）；命令面板「删除音符」点的是按钮、却标着快捷键 Delete。
- **统一成键盘 Delete 的语义**：`#eb-delcol2` 的处理（锚点 `if(e.target.closest('#eb-delcol2')){ deleteNote(); return; }`）改调 `delColumn`；`deleteNote` 保留函数名、改成调 `delColumn`（`tv_perf2` 直接调它）。理由：① 保住小节总时值——与 2026-10-31 拍板②「选区批量改时值保住小节总时值」、v68.8「空列改短补同值空列」同一原则，按钮现在删完就报时值错；② Delete 是熟手高频路径，规则已被 `tv_v696in` I5b / I5c、`tv_v688` FX1b / pk4 / pk8 钉住，反过来改等于改熟手结果；③ 命令面板早已把它标成 Delete，按钮跟着走才一致；④ 想留休止用 Backspace（清成休止、时值不动），三件事分工清楚：Backspace 清音 / Delete 删格补齐 / 删小节。
- 按钮提示：旧外壳原文「已删除音符」不动；新外壳 `toastSay` 短文案「已删除」；只剩一格时同 Delete（改成休止）。选区 / 整小节选中时的 Delete 不在本次范围，保持原样。

**测试（tv_v698in）**
